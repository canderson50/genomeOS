## Body

## Scientific objective

Expand the Atlas beyond a small set of structured frequency sources by adding an auditable literature-evidence path that may promote only independently verified, population-resolved, exact allele-count measurements into P1 observations.

This implements the literature evidence design §§1 and 4–8. It keeps measured evidence distinct from inferred surfaces and preserves a refusal as a valid outcome whenever the source cannot support a required fact.

## What changed

- Added frozen contracts for the 37-column record ledger, 19-row-per-record field-evidence ledger, and PubMed search manifest.
- Added stable, content-derived record and search identities; search IDs are recomputed from database, query, and execution time.
- Added a strict publication adapter that resolves an exact `literature` P0 alias and copies its latitude, longitude, and uncertainty radius unchanged.
- Added explicit refusal accounting for ambiguous variants, unresolved required fields, inexact/reconstructed counts, pending verification, unchecked reuse, and restricted reuse.
- Added allowlisted derivations whose results are recomputed from the raw evidence payload rather than trusted from an agent-provided value.
- Added stable P1 `source_record_id` values to the existing allele-count adapters and wired optional literature ledgers into the observations build.
- Added fixture-backed tests and a synthetic review figure demonstrating one complete P0→P1 path.
- Added a pinned audit of the upstream LCT/MCM6 rs4988235 dataset plus a PubMed ESearch manifest builder.
- Added a field-by-field curation guide with exact headers, required meanings, accepted examples, rejected examples, and anti-fabrication instructions.

## Safeguards against agent shortcuts

- No radius, coordinate, sampling design, disease-ascertainment result, cohort, denominator, count, or source locator is defaulted or inferred from a label.
- Missing facts remain null with structured evidence status; strings such as `unknown`, `TBD`, and placeholder locators are rejected.
- Every tracked scientific field requires its own evidence row and source anchor.
- Stored normalization, verification, and reuse statuses are recomputed and must agree with their supporting evidence.
- `original_source_verified` requires a distinct verifier identity and a durable GitHub review or immutable repository reference.
- Replicated measurements require distinct sample identities; duplicate cohort measurements are hard errors.
- Promotion accepts only exact counts (`ac_lower == ac_upper`) and never reconstructed frequencies.
- A completed reuse check with no explicit restriction is admissible as `no_restriction_found`; unchecked reuse and explicit restrictions still block promotion.
