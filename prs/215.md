## Scientific objective and scope

Add an independent numerical reference for the B0H population-heterogeneity
count model, then compare actual posterior sampling and count prediction on
predeclared nonconjugate synthetic cases. Advances #211 and #189; closes neither.
Closes #214 with an equivalent, numerically stable observed likelihood.
Implements Atlas design §§5,7,8,12 and the B0H spec's numerical-verification unit.
Stacked on research-core PR213, not a production or geographic model release.

- The validation-only likelihood uses explicit finite products, independently
  of PyMC and the production count scorer.
- Beta-weighted Gauss-Jacobi quadrature returns posterior evidence, first/second/
  cross moments and full small-count predictive masses. Finite-order estimates
  are explicitly not certificates of convergence.
- Exact analytical anchors test the reference before it judges the sampler;
  asymmetric priors detect swapped quadrature exponents.
- The frozen next check includes mixed, rare and unequal-denominator cases,
  primary/sensitivity priors, original/complemented counts and four quadrature
  orders. Computational error and posterior Monte Carlo error remain distinct.
- Those tests exposed a real failure:276divergences, with a trapped proposal
  assigned log likelihood+6160 instead of-26.757334358778397. The original
  failing regression and diagnostics remain documented; PR213 was marked draft.
- The localized fix evaluates the same normalized beta-binomial law with16
  exact log-domain factors and a stable shifted tail. It preserves priors,
  counts, observed-node semantics, sampler settings and all numerical/convergence
  refusals. No concentration cutoff, clipped draw or easier test was substituted.
- Independent400-digit value/gradient comparisons cover the captured point,
  maximumAN65536, extreme parameters and numerical branch joins. This is a
  bounded numerical regression domain, not a uniform floating-point proof.

## Limits and expert review

The reference's AN<=64 and order<=512 domain is for tractable validation, not
a change to production scoring. Prior-only quadrature is permitted to check
integration; the production fitter still refuses all-unavailable training.
No real counts, source genotypes, posterior arrays, coordinates or inferred
surfaces are committed or exported. No serving/schema/dependency change.
Direct PyMC prior/posterior-predictive random generation from the custom
observed node is unsupported; the existing public CountPredictive adapter
remains the prediction/scoring interface.

Expert review should examine numerical independence, refinement adequacy,
Monte Carlo error bounds and the scope of tested scenarios. Small-case
computational fidelity does not establish prior-SBC, resilience to shared
history, real predictive gain, geographical resolution or global AF accuracy.
Broader calibration/stress, benchmark integration and paired real comparisons
remain required #211 follow-ons. Existing clinical and promotion gates stand.

No map is emitted because this unit has no geographic inputs or surface output.
The PR #213 core and this corrective successor must land in order as one reviewed
research sequence; no production model or scientific release is published between them.
Retain the worktree for subsequent calibration research.
