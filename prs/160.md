**Correction — what this commit actually does, in two steps:**

**1. A fractional sample size is refused, not truncated.** `refuse(freq["n_indiv"].notna() & (freq["n_indiv"] % 1 != 0), "fractional_sample_size")` runs on the raw parsed float, before any integer cast, and before the duplicate check so the row is reported for its actual defect. Truncating would invent a measurement the source never published.

**2. One canonical integer, read by everything downstream.** `freq["n_individuals"] = freq["n_indiv"].where(keep).astype("Int64")` is built once after the safety checks, and is the only sample-size form the duplicate check, the count reconstruction, and `stable_source_record_id` read. The three rules can no longer disagree. `an` drops its `.round()`, since twice an integer needs no rounding.

The refusal goes through the module's existing `refuse()` helper, so the row is counted and named in the `IngestReport` and `retained + sum(refusals) == total` still holds. A silent drop would violate §12.
