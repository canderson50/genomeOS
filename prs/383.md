## Body

## TL;DR

We tested a spatial model designed to keep sickle-cell signal localized instead of spreading a low background across the world. It failed against the current spatial model: average absolute error was 28% worse, the probability score did not improve reliably, and error on surveys with zero observed copies nearly doubled. This PR records the negative result so we stop investing in this exact model.

## Result

All five geographic test folds completed on the same 994 held-out surveys used by the frozen B0 and B2 benchmarks. The final fits passed the registered convergence checks with zero divergences.

Against current B2:

- balanced macro MAE: `0.04198` versus `0.03281` (**28.0% worse**);
- balanced macro log-score difference: `-0.0641`, with outer-block 95% interval `[-0.2262, +0.1182]`;
- zero-count log-score difference: `-0.4869`;
- zero-count MAE: `0.02341` versus `0.01177`;
- only 80% interval coverage passed the ±3 percentage-point calibration tolerance; 50% and 95% failed.

B1G slightly improved probability scoring for positive-count surveys, but it worsened their absolute error and failed at the non-endemic zero-count behavior it was meant to repair. The result rejects this fixed B1G candidate; it does not reject every nonstationary or locally adaptive model.

## Scope and integrity

This advances #331 and #189. It does not close either issue because the requested spatial-statistics review and the wider program gates remain open.

The committed files are an aggregate JSON report, a review figure, and a plain-English evidence note. Observation-level predictions, checkpoint shards, logs, pod metadata, and the input bundle remain private and untracked. The report keeps `publication_eligible=false` and makes no promotion decision.

Expert review should check whether the negative zero-count result supports rejecting this positive compact-basis mechanism, whether the five-fold block interval is interpreted appropriately, and whether the observed 500/2,000 km radius instability suggests any defensible follow-up that would not amount to post-outcome retuning.
