## Body

## TL;DR

The model-selection benchmark was accidentally testing four inner data splits whenever an outer split left four geographic blocks. The project plan requires three. This change deterministically groups every retained geographic block into exactly three inner splits, keeps every block, records the grouping in the result, and refuses runs that cannot satisfy the rule.

Closes #374.

## What changed

- Add a pure, outcome-blind grouping function that balances original geographic blocks across `inner-0`, `inner-1`, and `inner-2` by record count. Ties are resolved by literal block ID and group index, so row order cannot change the result.
- Reuse the existing dependency and 300 km buffer splitter after grouping; no leakage or exclusion policy changes.
- Record the algorithm version, original block membership, and grouping hash for every inner fold.
- Validate checkpoint evidence against the frozen outer-training assignments and bump the fold-shard schema to version 2.
- Include the three-fold protocol and its source hash in campaign manifests.

The current four-inner-fold campaign remains separate development evidence. It must not be presented as evidence for the frozen three-inner-fold plan.

## Scientific contract

- **Objective:** make nested B1G model selection follow the prespecified five-outer/three-inner protocol without using allele counts, model outputs, or convergence outcomes to choose groups.
- **Acceptance evidence:** every feasible outer fold has exactly three nonempty inner folds; every original block appears once; groupings are deterministic; checkpoints retain and verify the mapping; five-block regression fixtures require 27 candidate fits plus one outer fit.
- **Interface:** `plan_three_inner_folds` freezes the mapping and `apply_three_inner_folds` applies it only to the exact assignment ledger that produced it.
- **Refusals:** fewer than three original blocks, duplicate identities, missing labels, changed assignments, malformed hashes, incomplete block coverage, or contradictory checkpoint evidence fail explicitly.

Implements design §§4, 8, and 12 and the nested-validation protocol in `docs/superpowers/plans/2026-09-09-global-af-modeling.md`.
