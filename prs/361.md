## TL;DR

The coverage badge no longer depends on the genomeOS website or GitHub's raw-file host. Our test workflow still calculates the percentage itself, then writes that number into the same reliable badge service already used for the license and version badges.

Closes #359.

## What changed

`scripts/render_coverage_badge.py` now updates both the website SVG and the percentage shown in README. The README image comes from Shields, while the coverage measurement remains our own pytest result. CI fails if either generated surface is stale.

The badge links to the CI workflow that produced the number. This is documentation infrastructure and does not change an Atlas scientific-design section.
