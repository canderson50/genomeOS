## Problem and resulting behavior

Reference count preparation needs an immutable, replayable artifact contract that distinguishes successful empty windows, retained `AN=0` rows, explicit refusals, and incomplete execution. The original implementation was embedded in the 17,042-line draft #287.

This focused slice adds strict acquisition/preparation codecs, typed preparation outcomes, pure row construction, and manifest-last artifact writers. Validation recomputes window ledgers, track structure and agreement, QC evidence, dependency edges, variant/window provenance, and parent hashes. It does not reparse retained cohort inputs or independently reconstruct count-row geography. An audit demonstrated that changing all four tables from the retained region label to the same forged label, then consistently recomputing the hashes and manifest, is accepted at this stack level. PR #351 closes that gap by replaying every expected row from the retained cohort and parent genotype evidence.

The tests also bring historical synthetic acquisition evidence under #349's stronger contract by ending every qualified sparse source with the canonical BGZF EOF marker. Invalid transport bytes can no longer masquerade as a verified parent fixture.

This PR is stacked on #349. Its review diff is seven files / 2,751 insertions. It advances #255 and #189 and closes neither.

**Merge requirement:** do not leave #350 as the head of the merged stack. Merge #351 immediately after it, or consolidate the two slices so the geography-replay validator lands atomically.
