## TL;DR

One test run of a simple comparison model was being discarded because an otherwise valid numerical result exceeded an outdated software limit. This change preserves and evaluates those results exactly for the tested study sizes, without clipping values or changing the model; larger unverified cases are still refused.

---

## What this changes, and why

The frozen B0H v2 calibration lost one otherwise valid fit because a sampled `rho` implied a beta-binomial concentration above the predictor's legacy `1/sqrt(float64 epsilon)` ceiling. The model admitted that posterior draw, but `PopulationHeterogeneityFit` rejected the entire artifact before diagnostics, making the frozen reduction ineligible.

This change separates artifact validation from operation limits. Valid finite posterior draws are retained through concentration `1e300`. For `AN <= 65,536`, draws above the legacy threshold use the independently accepted complete-support scaled-probability core; ordinary draws retain the existing finite-product mass and shorter-tail CDF. Unsupported high-concentration/larger-count operations still fail explicitly. No draw is clipped, discarded, or replaced with a binomial law.

The CuPy CDF now keeps the threshold decision at draw resolution. It groups observations that share the same high-draw mask, batches each dense subgroup through the appropriate vectorized kernel, and recombines subgroup sums over the unchanged total draw count. One exceptional posterior draw therefore no longer forces all ordinary draws for that observation through complete-support arithmetic. The support adapter selects the smallest proved vector width (32, 256, or 1024), so B0H's `AN=20` case avoids 1,024-wide temporary arrays.
