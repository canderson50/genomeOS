## Body

The existing reference pilot covers one linked 10 kb interval. This freezes 66 outcome-independent autosomal windows and checks whether their original generation-pinned source ranges can be acquired within a fixed 25 GiB budget. It adds strict geometry/provenance codecs, bounded TBI parsing and conservative range planning, plus an index-only CLI with complete window and refusal accounting.

The reviewed real preflight verified all 22 indexes (3,000,550 bytes). Its planned total is **2,351,476,474 bytes (2.189983 GiB)**: 65 windows have indexed chunks and `chr16-s2` has none. All 66 remain in the ledger. No VCF bodies or genotypes were acquired, and an index without chunks is not classified as allele count zero or a scientifically empty interval.

[Aggregate acceptance evidence](https://github.com/bschilder/genomeOS/blob/feat/global-af-reference-windows/docs/research/reference-window-preflight-2026-09-11.md) includes frozen hashes, exact execution revision and independent audit results. Index bodies, recovery records and participant-level material remain local. Wrapper invocation counts are explicitly distinguished from unobserved SDK metadata HTTP activity and wire bytes.
