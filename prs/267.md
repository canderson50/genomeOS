## Body

## What this changes, and why

Surface support previously divided every posterior frequency SD by the prior SD at the first observation. Finite HSGP and inducing representations have location-dependent prior uncertainty, so an unchanged local distribution could appear to have learned from data. In the synthetic figure below, that produces ratios as low as 0.832379 instead of 1.0 and falsely moves 12 of 414 evaluated land cells across the existing 0.9 support threshold.

This change computes the prior SD at each query using the retained model's `freq_pred`, actual hyperpriors and approximation geometry. The protocol is 500 prior draws, the fit's explicit seed, and population SD. Both cell consumers, plotting, publishing and export use the aligned denominator.

Owned legacy fits retain their posterior and graph without refitting or rewriting input. New fit caches use format 2, surface artifacts use format 3, and plot caches use format 2. Historical surface formats 1/2 remain readable. Plot caches preserve existing files, bind exact ordered query identities and seed metadata, and require a new path for incompatible old caches. New artifact validation rejects malformed formats, string/Boolean uncertainty columns and inconsistent ratios before publication creates a directory.
