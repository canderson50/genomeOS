## Experimental rulings

1. Run a separate timing spike while the permanent codec was developed. The inspection dumps cannot be promoted into final calibration evidence.
2. Use eight fixed initial attempts and no retry. This does not cover worst-case stress or full-study timing tails.
3. Run device checks before fit timing and label every phase. First-fit timing is not cold Python/CUDA startup or isolated JIT cost.
4. Use one sequential GPU and a 30-minute spike-process cap. An incomplete run would support no full-throughput claim.
5. Retain the small synthetic debug records and arrays with the report. This adds about 3.6 MB of independently checkable evidence without claiming archival compatibility.
