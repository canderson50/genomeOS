## Rulings I made

1. All-unavailable study3 is the explicit exception to the parent's general
   heldout sentence: no truth, heldout or scientific fit seed is fabricated.
   Cost if wrong: the later structural adapter needs rework.
2. Freeze scalar PCG64 call order, generation-based row IDs and raw Beta endpoint
   counters. Cost if wrong: a protocol-versioned rework, never silent reseeding.
3. Preserve lossless supported scalar domains instead of broad real-number
   conversion. Cost if wrong: uncommon rational/extended-precision callers need
   an explicitly revised interface; normal NumPy float64 sampling is unchanged.
4. Separate public result contracts from sampling, sharing six concrete public
   validation/construction helpers. Cost if wrong: module-boundary rework; no
   extra factory, registry, circular imports or private cross-module imports.
5. Keep cohesive cross-field result validation together under the hard module
   gate, documenting an exception to the preferred500-line target. Cost: a
   larger contract module for readers, with no omitted checks or compression.
6. Serialize only the three exact supported built-in numerical exception classes
   at individual RNG/shape calls; unexpected subclasses propagate. Cost: stricter
   failure accounting and an explicit later adapter outcome for unexpected errors.
7. Retain sampled_mean/rho failure evidence as float|int|None without narrowing
   invalid integers. Cost: the later codec must retain exact integers in these
   additional fields; successful parameter truth remains unchanged.
