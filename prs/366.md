## Body

## TL;DR

This adds the statistical model needed to test whether a few local geographic peaks can explain HbS allele counts without raising predicted frequencies across broad non-endemic regions. It also adds the fair nested evaluation that chooses the model settings using training data only. This PR contains code and synthetic tests only; it publishes no real HbS results and changes no production or serving behavior.

## Problem and resulting behavior

The merged basis preflight could construct the nine preregistered compact geographic representations, but it could not answer whether any representation predicts held-out allele counts better. This change fits the fixed B1G model and emits the same count-prediction object used by the existing B0, B1, and B2 benchmarks.

The fitted model keeps the registered low-background prior, nonnegative compact peaks, sampling-design effects, replicated-cohort effects, and beta-binomial survey variation. Held-out prediction evaluates every posterior draw and survey footprint with vectorized matrix multiplication.

For each outer geographic fold, the benchmark evaluates all nine fixed radius/basis-count candidates on inner training folds. A candidate must predict every inner held-out row and complete every fold. Selection uses the existing cohort-then-region macro integrated log score; exact ties choose fewer bases and then the smaller radius. Failed candidates and folds remain in the result ledger, along with every inner fit's seeds and convergence diagnostics.

This advances #331. It does not close the issue: the frozen real-data comparison against matched B0 and completed B2 results remains pending.

## Scientific scope

- Implements design §§4–8 and §12 for the research-side B1G challenger.
