## TL;DR

This adds the machinery to run the registered simulation that decides whether modeling an extra spatial “activity” process improves global allele-frequency predictions. The campaign is split into 720 independent, resumable GPU tasks, and the finalizer refuses to approve a real HbS fit unless every task is present, converged, tied to the exact registered inputs and code, and all predeclared scientific checks pass. This PR does not fit real HbS data or publish a scientific surface.

## What this changes

- Builds deterministic task manifests for all 18 registered simulation scenarios, both model arms, five outer folds, and feasible inner folds.
- Runs one task or an ordered shard in a persistent process so GPU workers can reuse setup and compilation work.
- Writes small, authenticated JSON artifacts containing the evidence needed for review while excluding live PyMC traces.
- Verifies all artifacts against the frozen manifest before aggregation, including the exact held-out populations for each split.
- Applies the predeclared paired decision gate across null, localized-signal, sensitivity, calibration, zero-count, positive-count, and convergence checks.
- Documents the reproducible manifest, shard, resume, and finalize workflow.

The code implements the simulation and decision boundary required by design §§4–5, §7, §8, and §12. It advances #384; the issue remains open until the registered GPU campaign has run and its result has been reviewed.
