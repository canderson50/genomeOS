## Body

## TL;DR

The two slow GPU workflows behind the global allele-frequency benchmark now run independent cases at the same time without allowing workers to write to the evidence database. Reference comparisons use two workers and finish 38% more cases per hour; calibration uses five workers and doubles throughput. The measured defaults cut GPU cost per case by 27.5% and 50.2%, respectively.

Completed work is saved before it is published. If the coordinator restarts, it publishes the saved result instead of rerunning that scientific stage. A failure stops new work while preserving jobs that were already running.

Closes #337

## What changed

- Added a bounded subprocess scheduler for reference-model comparisons, with deterministic result ordering, verified resume behavior, and a measured two-worker limit.
- Split calibration stages into preparation, isolated scientific execution, and single-owner database publication.
- Added a checksummed publication spool so completed worker results survive coordinator loss.
- Added exact prior-owner recovery while retaining the existing refusal to redeliver a stage whose result was never returned.
- Capped inherited BLAS/OpenMP thread pools before numerical libraries load.
- Recorded the measured worker boundaries, compact public reports, and regenerable figures.

The implementation changes orchestration only. It does not change priors, sampler settings, cases, folds, seeds, reduction gates, scientific schemas, or serving behavior. It implements Atlas design §§5 and 7–8.
