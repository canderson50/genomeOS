## Body

## Summary

The Natural Earth country borders now ship as a compact quantized binary (GOBD) instead of the 3 MB upstream GeoJSON. The file is **3.7× smaller** on the wire, decodes about 4× faster in the data worker, and draws the same borders at the same heights.

Closes #445.

## What changed

- **Generator: `scripts/encode_natural_earth_borders.py`,** tested in `tests/test_encode_natural_earth_borders.py`.
  - It reads `reference/ne_50m_admin_0_countries.geojson`. That is the same git blob, moved out of `website/public`, so the repository does not grow.
  - It refuses any source whose sha256 is not the pinned one (revision `ca96624a`).
  - It quantizes to a 10⁻⁴° lattice, builds shared arcs and delta-codes them.
  - It verifies its own output by decoding it before writing. Output is deterministic and written atomically.
  - `--check` fails when the committed file is stale.
- **Heights stay bit-identical.** Rounding moves 8 of the 101,052 drawn vertices into a neighbouring H3 cell. With elevation on, their border height would jump by up to 2.8 km (visible over the Gulf of Gabès).
  - The generator snaps those 8 vertices to the nearest lattice point inside their original cell, at every resolution the published grids use (today res 4).
  - A test fails if a published grid ever uses a resolution the generator did not snap for.
  - h3-py and h3-js give identical cells for all source and decoded vertices.
- **Decoder: `website/src/atlas/geometry/natural-earth-codec.ts`.** It runs in the data worker and fills exactly the buffers the GeoJSON parse filled, so the overlay code is unchanged.
  - Python and TypeScript run the same header checks, with one documented difference: JSON parsing in TS cannot tell `2.0` from `2`.
  - Each side has a test that pins its behaviour.
- **Catalog, export and docs.** The catalog's `context_sources[0].url`, `scripts/export_atlas_web.py`, the e2e fixture and the spec (§B.6.9, new §B.10) are updated.
- **Attribution.** The Natural Earth credit text is unchanged.

## Why this format

All candidates use the same 10⁻⁴ lattice. Decode times are cold medians in the data worker.

| Candidate | raw | gzip | vs today | decode | max error |
| --- | ---: | ---: | ---: | ---: | ---: |
| today: upstream GeoJSON | 3,083,490 | 1,022,612 | 1× | 17.3 ms | 0 |
| GeoJSON at 4 dp, 6 properties | 1,897,733 | 690,465 | 1.48× | 11.2 ms | 7.8 m |
| TopoJSON, shared arcs | 981,446 | 376,766 | 2.71× | 8.3 ms | 7.8 m |
| **GOBD (this PR)** | **704,592** | **278,523** | **3.67×** | **4.0 ms** | **8.7 m** ¹ |

¹ Rounding alone is off by at most 0.00005° (7.8 m). The 8 snapped vertices are one lattice step from their source, at most 0.00008° (8.7 m). That bound is pinned in tests.
