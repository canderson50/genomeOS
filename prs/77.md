**`docs/overview.md`** (583 lines), layered so contributors from any background can use it:

**`README.md`** — motivation first, then what we're building, the invariants, an honest status table, a documentation index, and contributing steps. The old Pan-UKB paragraph moved into the status table; local development instructions are unchanged.

## Two framings worth a look

- **The Pan-UKB API is presented as the trait and effect-size layer of the atlas** (category E in #3), not as a parallel product — multi-ancestry summary statistics are what turn an allele-frequency surface into a statement about a phenotype. Nothing in the docs stated the relationship, so this is an inference; say the word if it should read differently.
- **Every one of #3's five recommendations is traced to where it landed** in the design, so a contributor can see the design is derived rather than asserted — and where their own dataset corrections would propagate.

Sources: the Atlas v1 design spec, #3, #4, #2, #1, and the live board labels.
