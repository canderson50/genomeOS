## TL;DR

The coverage badge no longer loads its graphic from Shields, which can fail for some browsers and networks. It now uses the coverage graphic that genomeOS already generates and publishes on its own website. Clicking the badge still opens the CI workflow that measures and checks coverage.

Closes #359.

## What changed

- Pointed the README coverage image at `https://genome-os.org/_static/coverage.svg`.
- Made `scripts/render_coverage_badge.py` generate only the first-party SVG instead of rewriting README to a percentage-specific Shields URL.
- Kept CI's freshness check on the generated SVG.
- Added a regression test proving that badge generation works in an empty directory without a README checkout.

This is documentation and CI infrastructure. It does not change an Atlas scientific-design section.
