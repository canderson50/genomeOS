## TL;DR

This prepares four checked tables showing how often each retained variant appears in each source population. The tables use two approved participant groups and two quality settings. Every planned data section is accounted for, missing calls stay missing, and independent standard genetics tools check the totals. Individual genotypes and the large generated tables remain private.

---

## Problem and resulting behavior

The global allele-frequency campaign needed a reproducible path from the frozen #254 window plan to broader reference-panel count inputs. The original implementation in draft PR #287 was too large for honest review, so it was split into six focused layers and then consolidated here after review.

The complete implementation now:

- validates the reviewed manifest, source generations, tabix indexes, byte ranges, transfer budget, and pre-retrieval review before network access;
- reconstructs the exact 4,117-sample technical-QC cohort and nested 4,094-sample paper-ancestry cohort while preserving all 80 literal population labels;
- preserves PASS biallelic A/C/G/T SNP semantics, diploid dosage, missing-call denominators, and the distinct called and quality-filtered tracks;
- fetches only generation-pinned approved byte ranges, records partial/refused outcomes, and never presents sparse staging as a verified whole VCF;
- parses each retained record once and counts both nested cohorts in one pass;
- compares every retained variant with native bcftools cohort totals and retained native genotype tokens;
- replays every count row against parent genotype, cohort, window, and population-label evidence, so consistently rehashing a forged label is still rejected; and
- writes immutable artifacts manifest-last, with complete runtime, executable, source, and input provenance.

## Completed execution evidence

The reviewed historical run acquired all 22 chromosome sources and all 109 planned byte ranges across 66 predeclared windows. Sixty-five windows contained records; `chr16-s2` is retained as an explicit no-record result rather than replaced.

Preparation retained 32,415 PASS biallelic SNPs across 80 source populations. Each technical/paper × called/quality track has 2,593,200 rows, including explicit `AN=0` rows. Native bcftools totals match all 32,415 variants in both cohort stages, for 64,830 exact variant-level AC/AN checks. The aggregate report records acquisition manifest `14b61409...6a307` and preparation manifest `78543a6f...5221`.

The row-level acquisition, participant, genotype, token, and count artifacts remain private and untracked. The committed note contains aggregate evidence only.

## Scientific limits

This is reference-panel development evidence. Population labels describe source origins, not verified present-day residence. The 32,415 variants are linked and are not 32,415 independent loci. This work establishes no model improvement, calibration, P1 eligibility, publication eligibility, or public surface. No environmental or MAP covariate enters the preparation.

The independent native check covers cohort-wide called AC/AN. Population allocation and quality-filtered counts are validated by exact sample/token replay rather than by a second independently implemented population-level quality counter. The report states that boundary explicitly.

No map is included because reviewed resident geography is outside this task; drawing these source labels geographically would imply evidence the source does not provide.
