## Body

Closes #38. Implements design §7, §7.1b, §10.

This is the honesty guarantee: §4's first structural answer to Novembre & Stephens 2008 is that a fitted surface must state where it does not know, because interpolation manufactures convincing clines with no demographic cause.

## What it does

Four states per cell, with `prior_dominated` and `unknown` **excluded from every aggregation statistic on the same footing**, and the excluded fraction returned with the result rather than hidden:

| State | Meaning |
|---|---|
| `observed` | an observation centre falls inside the cell |
| `interpolated` | nearest observation within 2ρ, and the posterior contracted meaningfully |
| `prior_dominated` | data is in range but the posterior barely moved off the prior — **the state that matters**; rendering a prior as though it were data is the interpolation artifact in a new costume |
| `unknown` | no observation within 2ρ |

**The classification rule is a pure vectorised function with no model dependency**, so the guarantee is unit-tested without sampling — 8 of the 14 new tests run in milliseconds. State ordering follows §7: no observation in range is a stronger statement than a slack posterior, and an observation inside the cell outranks both.

**An aggregate over an entirely masked region returns `value=None`** — not `0.0`, not `NaN`. §9 requires emitting no number rather than a wrong one, and a zero here would read as "no carriers" rather than "we don't know."

## One thing worth a decision — raised, not absorbed

**A cell containing a very small observation is classified `observed` even if its posterior never contracted.** §7 orders that test first, so a cell with a single AN=2 measurement outranks the `prior_dominated` check — and `observed` cells are *not* excluded from aggregates.

Provenance ("something was measured here") and information ("we learned something") are different questions, and the four-state enum conflates them. Nothing is hidden — `posterior_contraction` and `eff_n_in_range` are emitted per cell regardless — but such a cell currently enters aggregates on the same footing as a well-measured one.

I implemented the spec as written rather than quietly deviating from it. Flagged on #39, since it is a calibration question: either the threshold logic should apply to `observed` cells too, or §7 should say explicitly that it doesn't and why.

## Implementation note

`posterior_contraction` is posterior sd ÷ prior sd. The denominator is **a single scalar**, not a per-cell quantity, because the GP prior is stationary and the mean function is location-independent — so the marginal prior of allele frequency is identical at every location. It's sampled once from the prior predictive at fit time rather than recomputed per cell.
