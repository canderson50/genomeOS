## Body

## Outcome

Advances #189 with actual, aggregate-only HGDP + 1KG source qualification and a fixed-interval
allele-count preparation pilot. Does not close the modeling program or publish an AF model,
genotype/count dataset, observation layer or scientific surface.

The observation-aware benchmark foundation from #203 is now on `main`. Relative to that
landed base, this PR adds only two research notes; there is no CuGen dependency, production
code, schema, dependency or serving change.

## Evidence

- All 478 public Hail sample-metadata objects acquired and checksum-checked; actual rows read.
- Exact release exclusions reconcile 4,117 technical-QC samples to the paper's 4,094. The older
  22-person flag set is retained as a distinct definition, not silently substituted.
- Fixed GRCh38 chr22:20,000,001–20,010,000 interval selected before count inspection. Indexed
  original-callset extraction yields 616 records; 510 PASS biallelic SNPs produce 40,800 cells
  across 80 source populations in each of two cohort stages.
- Independent bcftools recomputation agrees with all 510 called AC/AN cohort totals in each
  stage. This does not independently validate every population cell or quality-filtered count.
- Corrected a source display-label collision (78 labels vs 80 identities), preserving the
  superseded diagnostic. Retained three zero-quality-denominator cells as unavailable, not AF=0.
- Reported PC-Relate edges reveal four cross-population pairs, affecting three population pairs
  that must not be split naively between training and test.

## Scientific scope

Atlas design §§4, 7.1 and 8; global AF plan WP0/WP1. The notes distinguish observations from
inference, called from quality-filtered counts, partial-range from whole-object verification,
population origins from residences, and reported dependence from complete independence.

One short genomic block is not 510 independent locus replicates. This is not a model accuracy
result or a primary resident benchmark. Qualified footprints, ascertainment/date semantics,
count calibration, frozen comparisons, independent external confirmation and publication gates
remain open. Diagnostic code/data are retained locally; packaging the research-side interfaces
and reproducible commands is explicit follow-up work, not claimed complete here.

The #66 owner decision is recorded accurately as resolved, with attribution/biocultural notices
and explicit source restrictions required. No participant identifiers, genotype rows, local
scratch files or real count tables are committed or uploaded.
