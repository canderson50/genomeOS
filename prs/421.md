## Body

Closes #420.

The repository moved from `bschilder/genomeOS` to `genomeOS/genomeOS`. Old GitHub links redirect, but three things didn't survive the move:

**1. Container publishing.** The transfer unlinked `ghcr.io/bschilder/genomeos` from the repository, so the org repo's `GITHUB_TOKEN` can no longer push there, and the next `container` run on main would fail.
- `docker.yml` now publishes to `ghcr.io/genomeos/genomeos`. It is lowercase as ghcr requires, and the workflow already grants `packages: write`.
- The README and `docs/deployment-gcp.md` pull/run lines, package links and badges point at the new home.
- Images published before the move stay pullable at `ghcr.io/bschilder/genomeos`, and both docs say so.

**2. Pages fallback host.** `bschilder.github.io/genomeOS/` now 404s for this repo.
- `build-fallback.mjs` builds for `https://genomeos.github.io`. The fallback build and its link check pass against `/genomeOS/`.
- The deployment docs are updated to match.

**3. Site links.** These now point at `github.com/genomeOS/genomeOS`:
- the header GitHub link;
- the docs edit links;
- the Discussions and Issues links on the home, project, contribute and working-groups pages.

The project board link stays at `users/bschilder/projects/8`, since the board didn't move.

**Not changed on purpose:**
- Hugging Face `bschilder/genomeos-data` and `github.com/bschilder/cugen` are separate and didn't move.
- The `BSCHILDER_GITHUB2` RunPod secret name.
- Provenance URLs that scripts write into checked-in fixtures and research outputs, so regenerating gives identical files.
- About 180 documentation links that only redirect. They'll get a follow-up sweep once the in-flight PRs land, to avoid conflicts.
