## Body

## TL;DR

B1G chooses the best candidate using only its held-out log score, but it was also calculating prediction intervals and calibration statistics for every inner candidate fit. This change skips that unused work during candidate selection. The final held-out evaluation still calculates the complete error, coverage, interval, and calibration report.

## Problem and result

Each outer fold evaluates nine candidate configurations across three inner folds. The old path ran the full count-diagnostic pipeline after all 27 inner predictions, including seven exact quantiles that repeatedly call the mixture CDF. None of those interval diagnostics affect selection; issue #331 specifies mean cohort-macro integrated log score as the sole selection metric.

The inner path now computes and validates log scores only, using the same cohort-then-region weighting as the full benchmark reporter. Fitting, predictive draws, deterministic seeds, candidate eligibility, failure capture, tie-breaking, and outer-fold diagnostics are unchanged.

This advances #331; it does not close the scientific benchmark or make a promotion decision.

Design sections: §§4–8 and 12; issue #331 candidate-selection contract.
