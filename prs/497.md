## What this changes, and why

Agents skip a gate list that lives only in a doc, and `CONTRIBUTING.md` omits `check_commercial_use.py`. This adds `/gates`, whose steps are the Python job in `.github/workflows/ci.yml`: ruff, contract check, module size, private files, commercial-use, smoke, then pytest with `OMP_NUM_THREADS`, `MKL_NUM_THREADS`, `OPENBLAS_NUM_THREADS`, and `NUMEXPR_NUM_THREADS` set to 1. Invoke it as `/gates`. It does not run on its own.

The text pasted into the pull request is one summary line per command, the same shape merged PRs already use (the tool’s one-line result, or a pytest count such as `7145 passed, 52 skipped`). On failure, that line plus the failing test names. The verbose log stays local.

The second file is a read-only reviewer. After a diff exists it reads the current `AGENTS.md` and judges the diff against that file’s invariants, deliberate refusals, and publication-evidence safeguards. For each failure it names the file and cites the invariant it just read. It does not keep its own copy of those rules, it does not rewrite code, and it is not the verifier of literature it extracted.

Cursor stores the slash command at `.cursor/skills/gates/SKILL.md` (`disable-model-invocation: true`). The reviewer is `.cursor/agents/invariant-reviewer.md` with `readonly: true`.
