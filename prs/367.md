## Body

## TL;DR

The coverage badge can disappear because it currently depends on the project website. This change displays the 90% measured by our own GitHub test run through the same reliable badge service already used by the other README badges. It does not use Codecov.

Closes #359.

## Problem and result

`https://genome-os.org/_static/coverage.svg` is not reliable in every README client. The replacement `https://img.shields.io/badge/coverage-90%25-brightgreen.svg` returns HTTP 200 and has no dependency on a Pages deployment finishing first.

CI remains the source of truth: `pytest-cov` writes `coverage.json`, and `scripts/render_coverage_badge.py --readme README.md` updates the displayed percentage and colour. The CI freshness gate fails if either the committed SVG or README value differs from the measured result.

This is a README and CI reliability fix; it does not implement or change an Atlas scientific-design section.
