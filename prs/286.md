## Body

Users can inspect exactly what the selective association index contains and compare two published geographic maps without turning either operation into a trait-prevalence or pleiotropy claim. The new `/evidence` browser reports missing source checksums, unknown QC, unrecorded effect scales and unrecorded independent review. An empty index remains unavailable; it never receives seed/demo results.

The existing association importer now records SHA-256 from actual input bytes and refuses changed content under an already checksummed source asset in the same release. It does not certify a caller-supplied URI.

The website adds `/app/compare/` using the existing Cesium explorer. The two panels retain independent artifact identities, legends, measurements, observations and support masks. A shared provider loads complete real artifacts before sequential renderer startup. Camera synchronization treats equivalent circular angles correctly; controls and portals are scoped to each panel. Explicit selections and versions are URL-addressable, and invalid selections are refused.

Advances #282 without closing it. Implements Atlas design §§5, 6, 10–13 and the Cesium design §10. The approved delivery plan and local read-only audit are committed. Modules separate strict contracts, pure validation, SQL queries, HTTP, offline auditing, navigation and UI composition. Frozen contract diffs are included.

## Scientific limitations and remaining work

- The audited local database contains zero phenotypes, associations and releases. This is local availability, not a claim about the public Pan-UKB resource or deployed database.
- Registered source pointers/checksums establish traceability only; source content and independent scientific review are not certified by the reader.
- No counted-allele map joins, qualified GWAS/LD inputs, validated genetic-correlation/colocalization protocol, or gene-attribution/pleiotropy result is supplied. These remain open under #282. No substitute datasets or fallback methods were introduced.
- Map comparison is visual juxtaposition. No difference, correlation, blended quantity or genotype-derived phenotype heatmap is computed.
- Expert review should check effect/counting-allele semantics, phenotype identity and the limits shown in the interface before approving subsequent scientific work.
