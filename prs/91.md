## The data is open after all

Issue #3 recorded the MAP HbS survey database as *promised* to ROAD-MAP, and Piel et al. 2010/2013 give no download link — the 2013 paper only says it *"will be made freely accessible"*. It is: MAP serves it as the **`Explorer:HbS_Data` WFS layer**, no credentials.

1,287 surveys with genotype counts, coordinates, citations, and the inclusion flags for each Piel paper. `scripts/fetch_map_hbs.py` pulls it. **`Explorer:G6PD_Data` is there too**, which unblocks #46 the same way.

## The refusal that matters most

**A US newborn-screening row types only screen-positives:** 47,276 genotypes from 3,212,374 sampled infants. Take the genotyped subset as the denominator and the United States has an HbS allele frequency of **0.31**. Take `sample_size` and it's right — but that's wrong for the 207 rows where the shortfall is *other haemoglobin variants* counted in the sample but not in the HbAA/HbAS/HbSS triple.

Neither denominator is universally correct, so rows where the two disagree materially are refused. **Applying that rule alone drops the maximum observed frequency from 0.44 to 0.20** — the difference between a database that would have poisoned golden test 1 and one that won't.

`radius_km` now comes from MAP's recorded area class (1.78 / 2.82 / 5.64 km) rather than a constant, so §7's disc weighting uses real per-survey extent.

## API change

`load()` returns `(observations, IngestReport)`. A loader that discards three quarters of its input without saying so is what §12 forbids, so the count is in the return type rather than a log line. The build script prints it.

## Two decisions raised, not taken

- **#89** — 369 surveys report HbAA and HbAS but leave HbSS blank. Blank could mean "none found" or "not typed"; assuming zero biases frequency down *hardest where HbS is common*, which is exactly where parity is scored. Refused pending a haematologist's read of the source literature's convention. That single decision is worth roughly 26% → 55% retention.
- **#90** — the parity **target**. §8 scores against Piel et al.'s national AS/SS estimates *with intervals*, which live in the Lancet appendix PDF. PMC serves an anti-bot interstitial for it, so it needs a manual download and a checked transcription. `priority:critical`, because #45 cannot close without it.
