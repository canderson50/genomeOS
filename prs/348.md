## TL;DR

This defines exactly how each person's recorded genotype becomes a population-level count, including how missing data and minimum quality rules are handled. Both approved participant groups are counted in one pass, and the results retain enough detail for an independent check with standard genetics software.

---

## Problem and resulting behavior

Reference-window counts must preserve the original VCF call semantics: PASS biallelic A/C/G/T SNPs, complete diploid dosage, missing calls excluded from `AN`, and a separate quality sensitivity requiring GQ ≥20, DP ≥10, and heterozygote allele balance ≥0.2. The original implementation lived inside the 17,042-line draft #287.

This focused slice adds a strict VCF token boundary and pure count/QC derivation. It resolves `GT`, `GQ`, `DP`, and `AD` by FORMAT name, records whether missingness came from an absent field, trailing omission, or literal dot, preserves allele orientation, and refuses malformed or unsupported encodings. Native normalized tokens are joined by exact sample identity and compared only for fields the decision inspected.

The final path compiles each record's FORMAT projection once and accumulates the nested 4,117/4,094 cohorts in one source pass. Tests prove that paired counting is identical to two independent cohort calls and that malformed or disagreeing native normalization refuses.

This PR is stacked on #347 so its review diff is exactly four files / 1,617 insertions. It advances #255 and #189 and closes neither.
