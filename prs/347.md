## Problem and resulting behavior

The reference-count campaign must distinguish the source header, the 4,117-sample technical-QC cohort, and the 4,094-sample paper-ancestry cohort without collapsing literal population identities. The original implementation lived inside the 17,042-line draft #287, which was too large for honest review.

This focused slice reconstructs both cohorts from exact sample identities and retained exclusions, preserves all 80 literal population labels, joins cohorts to source columns in the source's actual order, and refuses duplicate, missing, reordered, or internally inconsistent identity evidence. An immutable `QualifiedCohortInputs` value binds the retained bytes to the parsed cohorts and the exact 4,151-column metadata-plus-control source identity.

The real-campaign entry point additionally pins all six private inputs by SHA-256 and checks the frozen 4,150 → 4,117 → 4,094 cardinalities. Generic structural qualification remains separate and cannot make a real-campaign identity claim.

This PR is stacked on #346 so its review diff is only the cohort boundary: 599 lines across one production module and one focused test module. It advances #255 and #189 and closes neither.

## Scope boundaries

- Implements reference acquisition design §2 and Atlas §§4 and 7.1 identity-preservation requirements.
- Contains no network, filesystem, environment, VCF parsing, genotype counting, geography inference, or publication path.
- Commits no individual-level data or restricted derived artifact.
- Preserves literal population identities such as `Han`, `NorthernHan`, `PapuanHighlands`, and `PapuanSepik`; it does not assign them coordinates or claim sampling independence.
