## TL;DR

This adds the tested probability and simulation foundation for the next sickle-cell modeling experiment. The candidate can represent a place as sometimes belonging to a locally active component, but it never declares that an observed zero proves the variant is absent. It scores the complete count distribution with the same accuracy and calibration measures used by the existing benchmarks. This PR does not fit real HbS data, run a spatial model, or promote a surface.

## Problem and resulting behavior

The current spatial model leaves too much low-frequency background, while the earlier global extra-zero model harmed positive counts and B1G made the zero-count error worse. Issue #384 therefore requires a simulation-first test of a spatially varying activity probability before another expensive real-data fit.

The new `ActivityCountPredictive` analytically integrates the unobserved activity state:

- zero counts receive probability from both the inactive state and ordinary beta-binomial sampling;
- positive counts receive beta-binomial probability weighted by the activity probability;
- CDFs, exact finite-count quantiles, log scores, interval coverage, MAE/RMSE ingredients, and randomized PIT all describe that same marginal law;
- posterior component correlation and uncertainty are reported without claiming that activity and conditional frequency are separately identifiable; and
- deterministic simulators retain latent truth only for synthetic assessment.

A hand-derived `AN=1` regression demonstrates the core identifiability warning: exchanging activity probability and conditional frequency can leave the complete observed-count distribution unchanged because only their product is visible. Larger denominators may add information, but a converged future fit will still need explicit component-dependence and marginal-stability checks.

## Scientific boundary

This implements the pure likelihood/predictive and simulation boundary from Atlas design §§7–8 and issue #384. It makes no biological claim about activity, presence, endemicity, migration, selection, or ancestry. No real observation, fitted surface, environmental covariate, private artifact, or serving path is changed.

This advances #384, #103, and #189. It closes none of them. The remaining #384 work is the registered null/localized simulation campaign on frozen geometry, including seeds 42/43/44, five outer folds, convergence checks, false-support measurement, and expert review before any real HbS fit.
