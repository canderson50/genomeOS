Plan only, no implementation. Stacked on #247 — review that first; this PR's own diff is the plan document.

Six tasks, each independently testable. **Two corrections to the spec**, found while writing the plan:

**Frozen contracts.** The spec said they stay untouched. Wrong — registry schemas *are* frozen, so this **adds** `contract/variant_normalization.schema.json`. No *existing* contract changes, which is the property that matters, and Task 1 verifies it explicitly.

**An invariant the spec does not actually enforce.** §5 says two independent resources must agree, but its own schema table only requires `reference_resource` to be present and versioned, not to name two. The plan follows the schema table and flags this at the top to be raised **before Task 5** — a machine check needs the field split in two, which changes the frozen contract and belongs in Task 1, not bolted on later.

**Task 6 exists because self-review found a spec requirement with no task.** My review of #207 asked the contributor for a coordinate-shape check that Task 4 supersedes, and nothing was scheduled to tell them. Left unscheduled, they could build the weaker version at any time.

**Task 5 is deliberately not a TDD cycle.** It is research whose output is reviewed rows, and refusal is a normal outcome rather than a failure to work around.

The plan's own acceptance evidence is that `website/public/data/atlas/catalog.json` is byte-identical to main afterwards. If that diff is non-empty, a published identity moved and the work is wrong.
