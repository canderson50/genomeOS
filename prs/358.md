## TL;DR

The repository's new coverage check made the test job much slower than usual, and its README image returned 404 until a separate website deployment finished. This uses Python 3.12's lower-overhead tracing engine and serves the committed badge directly from the repository, while keeping the same 90.19% coverage result.

Closes #357
Closes #359

## What changed

The CI test step now sets `COVERAGE_CORE=sysmon`. The setting is scoped to GitHub Actions, where the workflow uses Python 3.12, so local Python 3.11 development remains supported.

The README now loads `website/public/_static/coverage.svg` from the raw `main` branch. Its hyperlink still opens the CI workflow, and the image no longer waits for GitHub Pages to deploy.

This is release infrastructure and does not implement or change an Atlas scientific-design section.
