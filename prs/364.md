## TL;DR

This adds a fast check that builds B1G's proposed local geographic basis inside each held-out fold before any expensive GPU model fit. It chooses centres reproducibly, evaluates all locations with vectorized NumPy operations, preserves every grid cell, and refuses changed input files by hash.

This advances #331. It does not close the issue, fit the B1G likelihood, publish real benchmark results, or promote a model.

## What changed

- Added deterministic training-only centre selection from unique positive-count footprints, including the preregistered source-ID tie rules.
- Added the exact compact-support Wendland basis and bounded query-by-centre matrix evaluation.
- Added a pure five-fold preflight ledger that reports positive and zero geometric support separately and retains infeasible cells.
- Added an offline runner pinned to the three #331 input hashes. It records code revision, runtime, chunk size, dependency versions, and retained matrix bytes.
- Added synthetic tests for row-order invariance, tie handling, compact support, chunk-size independence, immutable matrices, fold preservation, refusal semantics, hash verification, and serialization.

This implements design §§4–8 and 12 for the first bounded #331 component. The serving path is unchanged and no environmental feature is introduced.
