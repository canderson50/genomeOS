## Body

## Problem and resulting behavior

Issue #32 had no frozen, reviewable variant-set artifact: CPIC gene-drug targets, candidate alleles, Mendelian/founder candidates, unresolved representations, and project-review state were not joined under one fail-closed contract. This PR adds immutable candidate release `v1-candidate.1`, its offline builder, frozen schemas, source snapshots, and provenance manifests.

The release contains 698 candidates: 689 CPIC-derived alleles and 9 manually sourced Mendelian/founder candidates. It represents all 128 active CPIC Level A/B gene-drug pairs across 29 genes. Coverage reports eight genes with no CPIC allele table and CYP4F2 with no allele carrying an admitted clinical-functional state. The SMN1 zero-functional-copy candidate remains explicitly unresolved because a single sequence variant cannot represent dosage, intragenic variants, and silent 2+0 carriers.

Every candidate remains `pending` project review and the release is `publication_eligible: false`. Consequently, the public selectors emit zero frequency-surface or affected-burden variants. The implementation does not treat CPIC level as an allele-level property or mistake a CPIC functional allele for verified disease penetrance.

## Scope and issue

Advances #32. It does not close the issue because an independent project expert must review and accept or reject the candidates.

Implements Atlas design §7.1 and enforces the server-side variant-class policy from §13. The science modules perform no network or file I/O; the offline builder owns snapshot verification and immutable publication.

## Review requested

Please check:

- the exact CPIC clinical-functional-state admission rule;
- observation types assigned to each candidate;
- the explicit refusal to flatten SMN1 copy state into one sequence variant.

CPIC source content is CC0 with requested attribution. ClinVar attribution is retained. GeneReviews material is citation/link only because its reuse terms restrict reproduction; no GeneReviews text is copied into the dataset.
