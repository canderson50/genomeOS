## Deviations from the plan — please review these three

**1. Layout: flat package, not `src/` + uv.** The plan's Context says "`bschilder/genomeOS` is an empty repo." It isn't any more — the Pan-UKB service landed in #75, and its `Dockerfile` does `COPY genomeos ./genomeos`. Following Task 1 literally would have clobbered a deployed service. The import paths the rest of the plan depends on are identical either way, so the Atlas modules are subpackages of the flat `genomeos/` package. Heavy deps sit behind an `atlas` extra so the API image doesn't grow. `AGENTS.md` records this so the mismatch isn't later "fixed" by mistake.

**2. A silent-coercion bug in the plan's schema — worth a close look.** The plan specifies `pa.Column(bool, nullable=False)` for `disease_ascertainment_excluded`. Under pandera's schema-level `coerce=True`, **a null silently becomes `False`** — i.e. *"this cohort was not disease-depleted"*, the opposite of the safe reading, and invisible in the data. An adapter that forgot the flag would mark gnomAD-derived rows as unbiased.

The plan's own test caught it (`overrides5` did not raise). Column-level `coerce=False` does **not** fix it — schema-level coerce wins in pandera 0.32 — so the column now uses pandas' nullable `"boolean"` extension dtype, which keeps the null as `<NA>` for `nullable=False` to reject. Parquet round-trip preserves it. **Spec §6 may want the same treatment for every boolean it defines.**

**3. The frozen contract was silently incomplete.** The plan's dataframe-level checks were inline lambdas, and `schema.to_json()` drops unregistered checks — so `ac_le_an` and `date_lower_le_upper` never reached `contract/`. A check whose removal never shows in a diff defeats the purpose of freezing the contract, and `ac ≤ an` is exactly what Plan 3's TypeScript client needs. Both are now registered through pandera's extension API and serialise by name.

Smaller ones: `tests/test_ingest.py` was taken by the Pan-UKB tests, so the new file is `tests/test_ingest_observations.py`; and two `pytest.raises(Exception)` asserts from the plan were tightened to the specific `SchemaError`, since a blind assert is satisfied by any failure including an unrelated bug.

## Incidental

Enabling ruff required bringing the existing Pan-UKB code clean (16 findings). All mechanical except two judgement calls, both kept behaviour-preserving: FastAPI's `Depends()` in argument defaults is declared an immutable call rather than suppressed (B008 is a false positive there), and `zip(..., strict=False)` in `tabix.py` makes current behaviour explicit — tightening to `strict=True` would change how malformed source rows are handled and belongs in its own change.

`pyright` is deliberately **not** adopted: introducing a type checker onto pre-existing code is its own cleanup and would have blocked this work.
