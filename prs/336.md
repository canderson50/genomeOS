## Body

## TL;DR

Some sickle-cell survey records from the Malaria Atlas Project do not state a precise geographic coverage area, but the old importer assigned them a 12.6 km radius anyway. That invented precision is removed: a record now needs an explicit, reviewed coverage radius and source before it can be used, and this change does not approve any real records by itself. The command-line tools also force themselves to use code from the same checkout, so an older installed copy cannot silently replace the reviewed rules.

---

## Problem and resulting behavior

The MAP HbS adapter converted missing, unrecognized, and unbounded survey-area labels into an ordinary 12.6 km radius. Bounded area classes were also converted to equal-area discs, although equal area does not bound distance from the reported coordinate. Those values could therefore masquerade as measured geographic support in fitting and buffered validation.

This change requires every otherwise-retainable MAP HbS row to provide an explicit positive `sampling_bounding_disc` radius plus coordinate and radius provenance. Raw area-only exports now fail before any P1 frame or output store is created. Existing count arithmetic, count refusals, cohort grouping, P1 schema, and immutable artifacts remain unchanged. No real MAP input is qualified by this PR.

The validator uses columnar pandas/NumPy checks and preserves the first offending survey in each actionable error. Current plotting, build, validation, publication, and export consumers use the curated-input contract. Each command pins imports to its own repository checkout, which prevents a shared editable environment from combining a reviewed script with stale scientific rules from another branch. The legacy RunPod launcher refuses its four HbS jobs locally because it has no qualified curated-input delivery path; this prevents a doomed billed pod from entering its intentional hold loop.

This implements Atlas design §§6–7 and §12, and advances WP0/WP1 of the global allele-frequency modeling plan.

Closes #190
