## TL;DR

This downloads only the preapproved portions of the reference dataset and verifies their size, digital fingerprints, and decoded genetic records. An incomplete, truncated, timed-out, or mismatched download remains a visible failure and cannot be treated as valid input.

---

## Problem and resulting behavior

Reference-window development inputs require generation-pinned, bounded byte acquisition with enough evidence to distinguish planned ranges, partial transfers, verified retained bytes, and sparse staging. The original implementation lived inside the 17,042-line draft #287, and its central I/O module later reached the repository's 800-logical-line cap.

This focused slice fetches exact metadata and byte ranges through the repository gcloud wrapper, records bounded process receipts, verifies size and hashes against the reviewed plan, stages only verified sparse extents, and replays BGZF/Tabix records against exact native-tool output. Failed, timed-out, truncated, over-limit, or mismatched work remains explicit partial/refused evidence and cannot become a verified source.

The former 852-line `reference_window_io.py` is now a 50-line compatibility facade. Fetch/staging is isolated in a 344-line module and qualified reading in a 503-line module, with no downstream import changes. Streaming CRC32C uses a precomputed table and bounded chunks rather than loading an artifact into memory.

This PR is stacked on #348. Its review diff is 13 files / 2,944 text insertions plus a 1.1 MiB deterministic synthetic BGZF fixture and tiny index/malformed controls. It advances #255 and #189 and closes neither.

## Scope boundaries

- Implements reference acquisition design §4.1 and Atlas §§4, 5, and 12 transport/evidence boundaries.
- Contains no real individual-level data or derived reference counts; every committed native file is deterministic synthetic test data.
- A sparse staged object is always marked incomplete and is never assigned a verified whole-VCF checksum.
- Contains no cohort selection policy, model fitting, geography inference, or publication path.
