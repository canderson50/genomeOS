## TL;DR

**What it does:** Adds `.github/CODEOWNERS`, naming @bschilder and @dwgoblue as owners of every path.

**Why it matters:** `main` is now protected by the **Protect main** repository ruleset. Changes must come through a pull request, force-pushes and branch deletion are blocked, and a PR needs one approving review **from a code owner**. With this file in place, only an approval from @bschilder or @dwgoblue satisfies that rule. Approvals from other collaborators still show on the PR but don't unlock the merge. Repository admins may merge their own PRs without a second approval, but nobody can push straight to `main`.

**Not yet:** requiring CI to pass. That waits for the CI path-filter PR, so website-only PRs aren't left waiting for a check that never runs.
