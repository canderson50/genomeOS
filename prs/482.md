## TL;DR

**What it does:** Data-store files are now served with `Cache-Control: public, max-age=3600` (one hour) instead of `public, max-age=31536000, immutable` (one year). The Atlas web bucket keeps its year-long cache.

**Why it matters:** No cache can be told to forget a copy. If a file ever had to be taken down, for example because a source turned out to restrict redistribution, a year-long header could keep it in readers' hands for a year. One hour bounds that. The owner chose this on 2026-10-17 (#473).

**Status:** After this merges, the 246 existing objects of release 2026-10-17 get the new header through a **metadata-only** update. Their bytes don't change. The post-upload check in `publish_data_store.py` compares the header, so the code change has to land first.

## Changes

- `genomeos/publication/data_release.py`: `IMMUTABLE_CACHE_CONTROL` → `CACHE_CONTROL = "public, max-age=3600"`. The web layer's own `IMMUTABLE_CACHE_CONTROL` in `web_layout.py` is untouched.
- `scripts/publish_data_store.py` and its test use the new constant.
- `docs/data-store.md` and the data-store design (C5, §9 item 6) record the decision.
