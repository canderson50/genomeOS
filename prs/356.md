## Body

## TL;DR

genomeOS now has an official Apache 2.0 license and five useful badges at the top of the README: license, project version, test coverage, CI status, and Docker package version. The coverage badge is produced by genomeOS itself from the full test suite; no coverage report is sent to an outside service.

## What changed

- Added the canonical Apache License 2.0 text at `LICENSE` and linked the license badge directly to it.
- Declared `Apache-2.0` in Python package metadata and verified that both source and wheel distributions include the full license.
- Added README badges for project version `0.1.0`, measured coverage, CI, and Docker package `v0.1.0`.
- Added `pytest-cov` and a small deterministic SVG generator. CI measures the full `genomeos` package, uploads `coverage.json` as a GitHub artifact, and fails when the repository-hosted percentage is stale.
- Updated the container workflow to read the version from `pyproject.toml`, publish the matching `v0.1.0` tag, and record it in OCI metadata alongside `latest` and the immutable commit tag.

The measured coverage is **90.19%** across 15,912 statements, displayed as 90% on the badge.

The license applies to project-authored source code and documentation. It does not relicense third-party datasets, model outputs, or bundled components; their source-specific terms remain controlling.

This is repository governance and release plumbing rather than a P0–P5 scientific implementation, so it does not change an Atlas design section or scientific result.
