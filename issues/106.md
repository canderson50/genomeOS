## Body

## Scientific/product objective

Prove that immutable Atlas evidence artifacts can be read through a bounded service and inspected
in a browser without running inference on the serving path.

## Engineering scope

- deterministic demo observation and surface Parquet artifacts with a versioned manifest
- concrete local artifact catalog and bounded DuckDB queries
- readiness, variant, observation, and surface endpoints
- structured JSON request and artifact-query logging with request correlation
- dependency-free diagnostic SVG preview
- container smoke test over read-only mounted artifacts

## Explicitly out of scope

- GCS, CDN, or BigQuery
- generalized storage protocols or factories
- polygon aggregation and burden serving
- Next.js, deck.gl, MapLibre, or a product UI
- runtime fitting or PyMC in the serving image

## Acceptance

- browser → API → DuckDB → Parquet works for the checked-in demo artifacts
- all responses include data and model versions
- masked support states remain visible
- logs are structured and exclude sensitive request/configuration data
- the serving container passes a read-only artifact smoke test
- repository smoke, lint, contracts, privacy, module-size, and full tests pass
