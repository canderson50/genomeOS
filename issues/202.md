## Scientific objective and invariants

The #191 unseen-cohort adapter must preserve actual posterior identity and refuse malformed
scientific arrays before conversion. Schema/contract violations are hard errors; plausible
numbers after lossy coercion are not acceptable. This is part of #189, design §§4–5, 7.1, 8, 12.

## Reproduction at unmerged `ec93d4af664ffaa25d08f2c3d83452bd63d9008b`

The independent whole-slice reviewer ran a read-only diagnostic with the existing controlled
`tests/test_observation_prediction.py` fixtures, changing only boundary values/coordinates.
Tool evidence `df81b3`; the controller subsequently inspected the implicated source branches.

1. `_extract_named_array` in `genomeos/surfaces/observation_prediction.py:114` applies
   `np.asarray(values, dtype=np.float64)` before the pure composer's type checks. Boolean,
   numeric-string and complex effect arrays all returned plausible means. A value `0.5+9j`
   became `0.5`, with only a ComplexWarning. Expected: explicit rejection of invalid original
   dtypes, for both posterior effects and generated latent values; ordinary real integer/float
   arrays remain supported.
2. `_extract_effects` returns no reference coordinates for a single-design binomial model with
   cohort/nugget omitted. The adapter then adopts generated latent coordinates at lines 224–226.
   With actual posterior coordinates `chain=[7,8], draw=[11,12]`, controlled boundary output IDs
   `((0,2),(0,3),(1,2),(1,3))` were accepted. Expected: validate and anchor all effects and latent
   output to the actual fitted posterior, even when no observation effect is present.

These are demonstrated malformed-input validation gaps, not a claim that normal PyMC fits
have been corrupted. No published surface, source data or serving behavior changed.

## Engineering acceptance

- Strict real-numeric validation before casting, with Boolean/string/object/complex refusal
  tests for effects and latent values and positive ordinary integer/float controls.
- Explicit nonempty, unique, integer chain/draw coordinates from the actual posterior before
  sampling, independent of effect configuration. Test successful no-effect alignment plus
  missing/malformed/mismatched coordinates and early refusal where determinable before draws.
- Keep actual draw IDs, query permutation behavior, immutable float64 outputs, legacy methods,
  priors, convergence criteria, exact same-mode compatibility and cache controls unchanged.
- Focused regression RED/GREEN, mandatory repository gates, final-source full suite and one
  scoped re-review of the complete final-review fix wave.
