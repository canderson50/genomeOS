## Body

## Scientific problem

The data-support mask interprets posterior SD / prior SD as learning from data
(design §7.1b). The inducing implementation has a location-dependent approximate
prior, but the denominator is sampled at the first observation coordinate and
reused everywhere. A difference between locations' priors can consequently cross
the contraction threshold even when the local distribution has not changed.

This advances #189 WP2 and #39. It is separate from #129's question of whether
biological correlation lengths should vary spatially. This report proposes no
change to the 0.9 threshold, the engine decision #34, or published artifacts.

## Source trace

Main was verified at `3c986902c12b40b84c56145ed863f7f519cbab6b` on September11.

- [`SurfaceFit.prior_frequency_sd`](https://github.com/bschilder/genomeOS/blob/3c986902c12b40b84c56145ed863f7f519cbab6b/genomeos/surfaces/fit.py#L350)
  explicitly justifies one scalar by prior stationarity.
- [`x_pred` starts at `x[:1]`](https://github.com/bschilder/genomeOS/blob/3c986902c12b40b84c56145ed863f7f519cbab6b/genomeos/surfaces/fit.py#L712).
- The [inducing training and prediction expressions](https://github.com/bschilder/genomeOS/blob/3c986902c12b40b84c56145ed863f7f519cbab6b/genomeos/surfaces/fit.py#L743)
  are deterministic given inducing coefficients. Their field covariance is
  `Q = K_xu (K_uu + jitter I)^-1 K_ux`, whose diagonal depends on the query location.
- The [scalar is estimated from that first-location prior](https://github.com/bschilder/genomeOS/blob/3c986902c12b40b84c56145ed863f7f519cbab6b/genomeos/surfaces/fit.py#L852)
  and [used for all cells](https://github.com/bschilder/genomeOS/blob/3c986902c12b40b84c56145ed863f7f519cbab6b/genomeos/surfaces/mask.py#L168).

This is the effective-prior distinction described by
[Quinonero-Candela and Rasmussen (2005), §§2,4](https://www.jmlr.org/papers/volume6/quinonero-candela05a/quinonero-candela05a.pdf).
The stationary parent kernel does not make its deterministic finite-rank
projection stationary. The omitted covariance `K-Q` is an additional approximation
question; correcting a denominator alone does not restore it.

## Minimal reproduction

Run in the repository's locked Atlas environment, with its source on PYTHONPATH.
This is authored synthetic geometry, not population or recruitment metadata.

```python
from itertools import product

import numpy as np
from scipy.linalg import solve_triangular
from scipy.special import expit, roots_hermitenorm

from genomeos.surfaces.fit import EARTH_RADIUS_KM, JITTER, h3_inducing_points, to_unit_sphere
from genomeos.surfaces.mask import MaskConfig, classify_support

anchors = np.array(list(product(range(-30, 41, 10), range(-20, 69, 8))), dtype=float)
u = h3_inducing_points(anchors[:, 0], anchors[:, 1], 16, 1500.0)
x = to_unit_sphere([anchors[0, 0], -25.0], [anchors[0, 1], 64.0])
length = 1500.0 / EARTH_RADIUS_KM

def kernel(a, b):
    r = np.sqrt(5.0) * np.linalg.norm(a[:, None, :] - b[None, :, :], axis=2) / length
    return (1.0 + r + r*r/3.0) * np.exp(-r)

chol = np.linalg.cholesky(kernel(u, u) + JITTER*np.eye(len(u)))
basis = solve_triangular(chol, kernel(x, u).T, lower=True).T
variance = 1.5**2 + np.sum(basis*basis, axis=1)
nodes, weights = roots_hermitenorm(256)
weights = weights / np.sqrt(2*np.pi)
p = expit(-3.5 + np.sqrt(variance[:, None])*nodes)
sd = np.sqrt(p*p @ weights - (p @ weights)**2)
anchor_xyz = to_unit_sphere(anchors[:, 0], anchors[:, 1])
chord = np.linalg.norm(x[1] - anchor_xyz, axis=1).min()
distance = 2*EARTH_RADIUS_KM*np.arcsin(chord/2)
for denominator in (sd[0], sd[1]):
    ratio = sd[1] / denominator
    state = classify_support(
        has_observation_centre=np.array([False]),
        dist_nearest_obs_km=np.array([distance]),
        posterior_contraction=np.array([ratio]),
        correlation_range_km=1500.0,
        config=MaskConfig(),
    )[0]
    print(float(ratio), state)
```

Observed: approximately `0.8953380210217113 interpolated`, then
`1.0 prior_dominated`. The distribution at the query is unchanged in both calls;
only the prior denominator changes.

## Acceptance evidence for a repair

- Specify whether contraction is measured against the implemented approximate
  prior or the intended parent GP, and make numerator/denominator consistent.
- Add a coordinate-aware prior calculation or another justified correction;
  do not label a single-location statistic stationary without demonstrating it.
- Test unchanged-prior normalization, query ordering/batching, H3/k-means coverage,
  HSGP separately, and save/load reproducibility on the actual prior-prediction path.
- Quantify the separate `K-Q` approximation using a small full-GP/count reference
  before claiming calibrated fitted uncertainty. No full inference or threshold
  change is authorized by the conditional diagnostic alone.
- Preserve existing cited artifacts; any corrected mask/model gets a new version.

Expert review should check the normalization target, conditional-to-full-prior
scope, approximation uncertainty, and implications for §7.1b support classification.
