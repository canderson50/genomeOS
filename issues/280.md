## Body

## Problem

`h3_inducing_points` ranks every candidate H3 cell only by its distance to the nearest
observation and retains `np.argsort(distance)[:n_inducing]`. When more candidates are collocated
with observations than the inducing budget, many distances are zero or differ only at roughly
1e-12 km. The selected geography then depends on platform-level floating-point tie noise.

This violates the deterministic-offline invariant and can change the finite inducing basis, local
approximate-prior variance and fitted surface between environments with the same config, data
version and seed.

## Reproduction

The synthetic land geometry in #267 supplied 59 resolution-1 H3 cell centres as observations,
with `n_inducing=16` and `reach_km=1500`. Candidate construction yielded 42,150 resolution-4
cells. Exactly 59 had nearest-observation distance below 1e-8 km (range 0 to
2.48e-12 km), so the top 16 were underdetermined.

On macOS with Python 3.12.13 / NumPy 2.4.6, this selected a basis whose diagnostic minimum ratio
was 0.764111. GitHub's Linux runner with Python 3.12.14 / NumPy 2.5.3 selected a basis whose minimum
was 0.796602. Reproducing the newer dependency versions on macOS retained 0.764111, isolating the
remaining difference to platform-sensitive numeric ordering rather than declared dependencies.

PR #267 now avoids relying on an underdetermined subset in its review-only figure by authoring 16
spatially balanced support sites and requesting all 16. It deliberately does not change the
production placement algorithm.

## Acceptance evidence

- Define a deterministic, geographically justified selection rule for over-budget candidates
  with equal or numerically indistinguishable observation distance.
- Preserve coverage near observations and H3 alignment; do not fall back to H3 index truncation.
- Add a regression with more collocated candidates than budget and perturb sub-micrometre distance
  values to prove that the same cell set is selected.
- Quantify spacing and conditioning changes on the current global benchmark before changing the
  default basis or model version.
- Preserve immutable existing artifacts; a placement change must produce a new model version.

This advances #189 WP2. Expert review should assess the tie tolerance and geographic coverage rule.
