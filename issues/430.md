## Body

Two browser tests on `main` fail intermittently under CI load. Both showed up on #429's first CI run (run 38080507930) and passed on rerun.

1. **`site.spec.ts` › "visible project names use the wordmark typography" fails on `/app/`** with `strong: missing wordmark`.
   - The basemap picker's button renders the selected basemap label in a plain `<strong>` (`EarthStylePicker.tsx:239`, also `:274`). The default basemap is "genomeOS Dark" (`earth-style-catalog.ts:18`), so the project name appears without the `brand-name` wordmark styling.
   - The test only catches it when the picker has mounted by the time it scans the page, which is why it is intermittent. The unstyled name is a real UI defect, not just a test race.
2. **`atlas-mobile.spec.ts:1836` › "the legend strip keeps its row and shows the loading status during a cold reveal" fails with `Expected <= 1, Received 4`** on phone projects.
   - It reproduces locally under 4 workers: 4 of 12 runs failed on `main` at 06a201e.
   - It predates #428 and #429.

Both need a root cause and a fix, not retries.
