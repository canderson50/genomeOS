### bschilder, 2026-08-24T20:29:26Z (https://github.com/genomeOS/genomeOS/issues/39#issuecomment-5400940387)

Two calibration inputs landed with the mask in #38, both currently placeholders:

- **`contraction_threshold = 0.9`** — a cell whose posterior sd is still ≥90% of the prior sd is marked `prior_dominated`. Chosen to be obviously provisional rather than defensible.
- **`hsgp_m = (8, 8)`** — HSGP basis functions per spatial dimension, from #35. This is the accuracy/cost dial that replaces the SPDE mesh resolution, so it belongs in this calibration alongside the resolution-promotion thresholds.

**And one design question this calibration should settle**, rather than leaving implicit:

§7 orders `observed` before the contraction test, so a cell containing a single tiny observation (AN=2, say) is classified `observed` even when its posterior has not contracted at all — and `observed` cells are not excluded from aggregates. Provenance and information are different questions and the four-state enum conflates them.

The HbS calibration is where this becomes measurable: MAP survey sites have wildly varying AN, so the fixture will contain exactly these cells. Two ways out —

1. apply the contraction test to `observed` cells too, so a measured-but-uninformative cell is marked `prior_dominated`; or
2. keep §7's ordering and state explicitly *why* provenance outranks information, so the choice is visible on the layer info panel rather than implicit in the enum.

Worth deciding on evidence from the HbS fit rather than from first principles.

### bschilder, 2026-09-16T01:30:05Z (https://github.com/genomeOS/genomeOS/issues/39#issuecomment-5690652787)

The canonical 994-survey HbS run in PR #301 provides two calibration results for this issue:

1. With the fitted sparse GP and current mask rule, the 77,844 populated res-4 cells classify as 2,398 `observed`, 59,536 `interpolated`, 15,910 `unknown`, and **0 `prior_dominated`**. Propagating values into masked cells changed the corrected global total by only 0.07% for HbSS and 0.61% for HbAS and did not improve the national gate. The current parity failure is therefore not caused by masked-cell exclusion.
2. The 150-point inducing basis is already over-dense relative to the learned field: median inducing spacing / posterior correlation range = 0.195, below the 0.25 efficiency warning. Adding more inducing points is not a useful next calibration arm.

The fit's remaining failure is field shape: a diffuse non-endemic floor inflates carrier burden while flattened endemic peaks depress affected births. The next bounded surface comparison should jointly test an explicitly low background plus local departures; shortening the range alone leaves the global intercept floor intact.

This run does **not** by itself settle the observed-before-contraction policy. Because no supported cell entered `prior_dominated`, the next experiment should report contraction by provenance and observation AN before choosing the threshold. That preserves the open decision in this issue rather than treating zero `prior_dominated` cells as proof that the placeholder threshold is calibrated.

The full fit identity, geographic diagnostic, denominator correction, and failed acceptance metrics are in PR #301 and the #45 comment.
