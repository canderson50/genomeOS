## TL;DR

Phase 2 of the public data store (#468): publish the raw third-party harvests that were never in git, each with the terms metadata the repository already records. Nothing here is implemented yet.

## Why

The owner's goal is that raw data, harmonized data, surfaces and trained models are all available to everyone. Phase 1 published everything that was in `data/`. The harvests below live only on maintainers' disks and in the interim Hugging Face mirror (`scripts/sync_store.py`).

Other acquisition pipelines (reference windows, the CuGen LD pilot, Earth Engine covariates) keep their own source manifests. Inventory them before deciding.

## Implementation notes

- Extend `INCLUDE`, the reviewed source rules and the terms table in `scripts/build_data_release.py`. Carry each `commercial_use` block and non-commercial marker exactly as recorded, and add a media type such as `.tif` to `genomeos/publication/data_release.py` deliberately.
- Files over about 150 MB can trigger gcloud parallel composite uploads, which have no md5. Either disable composite uploads for these files or verify by sha256 GET only.
- A `not_checked` source is publishable and stays honest. Recording a real terms check for MAP and WorldPop first would be better.
