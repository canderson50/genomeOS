## Body

## Observed bug

`scripts/check_private_files.py` admits internal `.superpowers/sdd/` working
reports. During the owner-authorized modeling work, an implementer accidentally
force-added an internal report; the tracked-file gate still returned success.
Exact staged-path review caught it before any push. The report was preserved
locally, removed from the index and the latest unpushed commit amended. No
credentials were present in the inspected report, and no affected commit was
pushed. This report does not disclose internal report contents.

## Reproduction

At scientific source `df0b71dfca1edd2c209abe8f9829cd103feaffdd`, in the locked
Python environment:

```python
import runpy
gate = runpy.run_path("scripts/check_private_files.py", run_name="gate_probe")
print(gate["forbidden_path"](".superpowers/sdd/example/task-2-report.md"))
```

Observed: `False`. Expected: `True` for internal SDD scratch. The current
forbidden path parts list does not contain `.superpowers`. Ignoring the directory
does not prevent a forced add, so ignore rules alone do not enforce this boundary.

## Contract and acceptance evidence

Claim: internal agent coordination caches must not become tracked deliverables.
Component: the existing tracked-file privacy gate and its focused regression
tests. Acceptance: reject `.superpowers/sdd/` reports/briefs/ledgers, including
nested paths; continue accepting intentional tracked documentation under
`docs/superpowers/`. Preserve existing credential/path checks and mandatory CI.
Assumptions: this is path admission, not a claim to scan all historical objects
or prove arbitrary files contain no secrets. Do not silently expand the scope to
history rewriting, credential rotation or other worktrees.

Filed separately to avoid widening the B0H scientific unit. All four label
families are applied; implementation and PR remain separate work.
