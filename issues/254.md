## Body

This is a bounded WP0/WP1 continuation of the owner-authorized global AF modeling program in #189. It advances that program without changing the frozen single-locus B0/B0H comparison or starting another model fit.

Scientific objective: extend the original gnomAD v3.1.2 HGDP+1KG reference-panel development dataset beyond the inspected chr22 pilot, with outcome-independent genomic coverage and the same count target. This does not qualify present-day resident geography or independent loci/studies.

Measurable deliverable: a deterministic 66-window manifest (three 10 kb windows per autosome, one uniformly jittered within each of three physical strata; seed 42), exact released VCF/TBI generations, and a bounded indexed-byte preflight. Selection excludes overlap with the prior chr22 [20,000,000,20,010,000) pilot by geometry before randomization. No external mask, outcome-based replacement, minimum-distance independence claim, genotype/count inspection, or model fit belongs to this issue.

Engineering interface: pure typed coordinate and TBI range-planning functions with thin offline manifest/preflight adapters. Keep acquisition status and provenance separate from ReferenceCount rows. Record a hard 25 GiB ceiling for total planned compressed bytes including index/header/tail reads, merged per source generation; refuse over-budget plans instead of reducing windows after outcomes.

Acceptance: reproducible coordinate bytes and hashes; endpoint/stratum/pilot-exclusion tests; generation-bound source identities; bounded strict TBI parsing; native tabix/bcftools cross-check on synthetic fixtures; explicit empty-index-window and failure states; file-size-aware merged range accounting; schema/refusal, smoke, privacy and full CI checks. Preflight may fetch public index bytes and inspect source metadata; genotype extraction is a subsequent separately frozen step.

Assumptions and consumers: same released dense adjusted genotype callset, GRCh38 header-declared lengths, 80 literal source population labels, technical-QC and paper ancestry stages kept separate, called/quality sensitivities unchanged in the later extractor. Additional windows remain development evidence. Unavailable/empty windows remain in the ledger; no zero-count fabrication. Population and whole-locus/chromosome holdouts are separate future comparisons, and shared participants, kinship, discovery and QC dependencies remain explicit. Real B0H comparisons wait for the separately frozen calibration gate.

Design references: Atlas §§4–8,12; global AF plan WP0/WP1. Source metadata audit has confirmed 22 autosomal VCF/TBI pairs and matching official VCF checksum metadata, not byte-level whole-file integrity. The official release provides generation-addressable public objects; every byte request must use the frozen generation. No participant-level data or recovered private session state will be committed/uploaded.
