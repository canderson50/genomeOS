## Bug and scientific contract

On `feat/global-af-sbc-quantities` at `f9f49b38a36f6b44484c035ff3a2d98c36c649a0`,
the public `SelectedSbcQuantities` constructor admits inconsistent restored
evidence. This violates the frozen selected-quantity design's scalar-length and
parent/control-state requirements (Atlas design §§5,7–8,12). Related to #211/#189.

1. Objective: retain scientifically consistent point-aligned quantity evidence
   and truthful control-failure states, without claiming invocation provenance.
2. Acceptance: regression tests fail on this revision and pass after the fix;
   all existing focused, smoke and full final-head checks remain unchanged.
3. Component/interface: `genomeos.validation.heterogeneity_sbc_quantity_types.SelectedSbcQuantities`.
   The enclosing record knows its actual canonical points and control outcome.
4. Assumptions/refusals: successful scalar vectors match all actual points;
   `control_failed` is legal only for mode1 when the parent control failed.
   No new fitter, seed, reference, numerical threshold, schema or retry policy.

## Reproduction and observed result

Using the existing constructor-valid synthetic `fixture()` and `install_mocks()`
helpers in `tests/test_heterogeneity_sbc_quantities.py`, create one valid result
with `selected_sbc_quantities(data, attempt=attempt)`. The numerical-reference
fixture here is explicitly mocked; no NUTS or real-data study is involved.

- Replace q3 or q4's successful values with `(0.0,)`, then reconstruct the
  enclosing result using `dataclasses.replace`. It currently accepts one value
  for thirteen points.
- With a completed parent control, replace mode1 q0 or q5 with a structurally
  valid `control_failed` rank (rank/comparisons/error all None), then reconstruct
  the enclosing result. It currently accepts the false failure state.

Root's bounded actual constructor probe printed, exit0:

```text
constructed fixture: 13 points; control complete
malformed scalar accepted: 3 1
malformed scalar accepted: 4 1
false control failure accepted: 0 complete control_failed
false control failure accepted: 5 complete control_failed
```

The task reviewer identified the scalar-length omission; root confirmed it in
an enclosing result and identified/confirmed the related control-state omission.
The normal execution path's checked numerical returns are not the missing
boundary: restored/enclosing construction must enforce these invariants too.

## Expected result and bounded fix

Both malformed reconstructions raise ValueError. Check `len(values)==len(points)`
for every successful scalar in the enclosing record, where P is known; leave
failed scalars' None values valid. Check the complete parent dependency for
control_failed across scalar and dependence quantities. Add regressions covering
both13-point completed controls and9-point failed controls, short/empty/long and
opposite-map vector lengths, and contradictory control states. Preserve valid
existing complete/failed outcomes and all mathematical/numerical contracts.

This is a correctness fix inside the requested diagnostic component, not a new
feature or a global-model improvement claim. Include the regression issue in
the eventual component PR; it advances but does not close #211/#189.
