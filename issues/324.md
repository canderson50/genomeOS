## Body

## TL;DR

There is a dataset of Middle Eastern and North African allele frequencies that we want, and it now
exists in exactly one place on the internet: a mirror last updated in December 2019. The official
copy is gone, and the Internet Archive saved the download page but not the files.

We should copy it into our own storage this week. It is a single command and about 10 MB.

---

## What it is

The Greater Middle East Variome: 1,111 exomes spanning Morocco to Pakistan, published in Nature
Genetics in 2016. It is the only open allele-frequency table covering that region broken down into
subregions rather than pooled.

## Why this is urgent rather than merely useful

- Its host, `igm.ucsd.edu/gme/download.shtml`, returns **404**. The server is alive; the resource
  was removed.
- The Internet Archive captured the HTML page but **never the files behind it**, so the archived
  links 404 too. There is no recovery path there.
- The surviving copy is bundled in a third-party annotation tool's data directory and was last
  modified **2019-12-05**. Nothing suggests anyone is maintaining it.

Verified live:

```bash
curl -O http://www.openbioinformatics.org/annovar/download/hg19_gme.txt.gz   # also hg38_gme.txt.gz
# HTTP 200, 10,416,934 bytes, Last-Modified Thu 05 Dec 2019
```

The payload is the real per-subregion table:

```
#Chr Start End Ref Alt GME_AF GME_NWA GME_NEA GME_AP GME_Israel GME_SD GME_TP GME_CA
1 69270 69270 A G 0.698113 0.642857 0.564246 0.677778 0.666667 0.863636 0.848214 0.868852
```

## What to do

1. Mirror both builds into our own storage with a checksum and a retrieval date.
2. Record the provenance honestly: retrieved from a third-party mirror because the authoritative
   source is gone, with the mirror URL and its last-modified date.
3. Check the mirror's own redistribution terms before we republish anything derived from it. The
   original download page carried **no terms at all**, which is a completed check finding no
   restriction, not an open licence.

## Two things to get right when we use it

**The regions are supranational by design, so this is G2 not G3.** The authors rejected country
borders deliberately: "Country boundaries were not used to group samples... Current country borders
frequently fail to accurately separate ethnicities." Northwest Africa alone spans Morocco, Algeria,
Tunisia and Libya. Drawing those seven polygons is our own reviewed-alias decision, and it needs an
uncertainty radius that honestly reflects a multi-country block.

**The paper describes six subregions; the released file has seven columns.** The paper's
Persia-and-Pakistan group does not appear in the file, which instead has Central Asia and Israel.
How they map is undocumented anywhere we could reach. Do not guess — record it as ambiguous.

## An unusual bonus

This resource answers the ascertainment fields the schema refuses to default, in the authors' own
words: the samples "were not a random sample, they were ascertained within a wide variety of
distinct phenotypes," and they "removed from datasets the allele that brought the family to medical
attention." That is a real, citable value for `sampling_design` and `disease_ascertainment_excluded`
rather than a refusal. Rare for a resource this old.

Assessed in #3, section H.
