## Body

Every PR waits about an hour on two serial steps, measured on #408's runs:

- Pages `validate` → 'Run browser and accessibility contracts': **58.7 min**. That is 252 Playwright tests (desktop + phone) on one worker with `fullyParallel: false`, and each one boots the Cesium globe under software WebGL.
- CI `test` → 'Test': **49.0 min**. That is about 6,500 pytest tests in one process with `--cov`; the same suite takes 21 min locally without coverage.

Everything else in both jobs takes about a minute in total.

Plan:
1. Run Playwright as a 4-shard matrix job, using test-level sharding (`--fully-parallel --shard=i/4`). Keep one worker per shard. `build` and `deploy` then need `validate` and all shards to pass.
2. Run pytest with `pytest-xdist -n auto` (pinned exact), with coverage combined. Verify the pass/fail/skip counts and coverage match the serial run.
3. Optionally, make local Playwright parallelism and the port opt-in through environment variables, so local gate runs can parallelise without changing CI defaults.

Target: under 20 min for each workflow.
