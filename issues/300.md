## Body

## Scientific objective

Make the HbS golden test compare like with like: Piel et al. report 2010 annual neonatal burden, so the burden denominator must reproduce Piel's 2010 national population totals while retaining a named gridded source only for within-country spatial weights.

## Observed failure

The 2026-09-16 acceptance run used the current `worldpop-res4-2020-plus-cok.parquet` population values directly. Across countries shared with the Piel table, assigned WorldPop population was 7.552B versus 6.882B in the reference. The mismatch is concentrated in high-burden countries: Nigeria 1.35×, DRC 1.69×, Angola 1.91×, Cameroon 1.47×.

With otherwise identical surface draws, support and burden equations:

- 2020 grid values: HbSS global median 346,036; HbAS 8,242,747.
- WorldPop used only as within-country weights, rescaled to Piel 2010 populations: HbSS 253,080; HbAS 6,471,133.

Both runs still fail #45, but they diagnose different model errors. A runner that does not bind the denominator year can therefore produce a scientifically misleading parity result while remaining numerically valid.

## Measurable output and acceptance evidence

- A pure function accepts per-cell `iso3,population` weights and an explicit per-country target population.
- For every aligned country, output cell populations sum to the exact declared target within a documented numerical tolerance.
- Duplicate/missing/nonfinite/nonpositive targets, nonfinite/negative weights, countries with no positive spatial weight, and input rows without an explicit alignment policy are hard errors.
- The output records the original gridded source/version, target source/year, and per-country scale factor.
- Focused tests cover unequal growth, zero-population cells, partial country coverage, input reordering, and every refusal.
- The HbS parity runner uses this boundary before applying Piel's crude birth rates and records `REFERENCE_YEAR = 2010`.

## Engineering component and consumers

Add the narrow pure alignment function to `genomeos.burden.national` (or a focused sibling if module size requires it), then call it from the offline national-estimate/parity adapter. It must not affect the serving path. Primary consumer: golden test #45; later year-specific burden comparisons can reuse the explicit contract.

## Assumptions and refusal conditions

WorldPop 2020 is used only to distribute a declared national total within a country. This does not claim that 2020 settlement patterns exactly reproduce 2010 patterns; that approximation must remain in provenance. Do not infer a target for countries absent from the reference, silently retain their 2020 total, or renormalize across countries.

Advances #45. Related closed rollup issue #94.
