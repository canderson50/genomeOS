### bschilder, 2026-09-15T23:21:27Z (https://github.com/genomeOS/genomeOS/issues/21#issuecomment-5689472406)

Resolution: retire the request for public-source-derived HGDP radii as a documented refusal. This closes the unsafe default without manufacturing replacements.

Evidence now covers the relevant source classes:

- PR #263 removed the panel-wide 50 km constant. The adapter now requires an explicit positive `uncertainty_radius_km` and provenance for every input row; unsupported real rows cannot enter P0. Its checked-in radii are explicitly synthetic fixtures.
- The CEPH provider table describes **geographic origin**, mixing point-like cells and broad ranges. It does not define collection/recruitment footprints, participant residence, uncertainty distributions or error radii.
- The recovered Cann et al. supplement map shows population-sample positions as point markers, without bounded support or recruitment semantics. Its missing workbook is described by the primary landing page as origin and LCL counts, which would still not establish a footprint.
- Qualified gnomAD HGDP+1KG metadata describes approximate population origins and supplied no explicitly named residence, recruitment-footprint or collection-date field.
- Hollenbach/CEPH conflicts tracked in #264 and Rosenberg's explicitly derived range-centroid coordinates show that published analytical coordinates are not interchangeable collection evidence.

Additional bounded recovery on 2026-09-15 found zero Arquivo.pt captures for the exact `CannWebTable.xls` URL, no structured supplement relation in Crossref, no independently inspectable exact-name web result, and only ambiguous HTTP 403 responses from plausible current Science paths. This does not prove the workbook is absent; it establishes that further workbook recovery is unnecessary for the radius decision.

Decision:

- Do not derive radii from origin strings, coordinate precision, printed ranges, centroids, marker size, or disagreement between sources.
- Do not use HGDP origin coordinates as primary evidence for present-day-resident spatial accuracy or the 300 km footprint-buffered validation track.
- HGDP remains useful for clearly labeled reference-panel development, count-model checks and genomic-structure features, subject to their existing limitations.
- Reopen only if population-specific primary documentation supplies collection or recruitment support with semantics suitable for an explicit uncertainty model.

This issue is closed as **not planned** because the requested real per-population radii are unavailable from the inspected public evidence. Refusal is the scientifically valid outcome; no registry row, observation, model or surface is promoted by this decision. The coordinate-provenance and conflicting-source records remain separately tracked in #219 and #264.
