## Body

## Product claim

Renderable Atlas changes must produce a deterministic, reviewable figure without attempting to draw the entire production geometry in a headless software-WebGL session.

## Reproduction

Run `cd website && npm run capture:atlas`. The build succeeds, but `capture-atlas.mjs` times out after 60 seconds waiting for `[data-atlas-ready=true]` because the capture path loads the full 77,844-cell surface. Browser tests already solve the same constraint with `installAtlasBrowserFixture`.

## Measurable output and acceptance evidence

- The capture script reuses the deterministic browser fixture geometry budget.
- `npm run capture:atlas` completes and refreshes `docs/figures/cesium-globe-explorer.png`.
- The resulting screenshot visibly distinguishes measured observations from the inferred surface and unknown/prior-dominated support.

## Engineering interface

Reuse the existing browser fixture at the Playwright page boundary; do not alter shipped Atlas data or production rendering.

## Assumptions and consumers

This compaction is capture/test-only. Full static artifacts remain separately asserted by browser tests. Consumers are PR reviewers and documentation readers.
