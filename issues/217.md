# Floating-point literal makes the dependence nonconvergence test nonportable

## Scientific / engineering contract

The dependence reference must retain the actual finite quadrature evidence and
report an unresolved point when adjacent order gaps exceed 1e-6. The test must
check that contract without assuming a decimal perturbation survives floating
point addition and subtraction exactly. No scientific threshold or production
method change is proposed. Downstream consumer: B0H SBC reference validation.

## Reproduction and actual evidence

PR #216, head ff059b557b0589bc5a2e583e8832f12d70381dd7, Linux Python 3.12.14:
https://github.com/bschilder/genomeOS/actions/runs/34452340663/job/102790702037

`tests/test_heterogeneity_dependence.py::test_reference_retains_all_finite_evidence_when_order_gaps_do_not_resolve`
fails at `assert point.error_bound >= 2e-6`: actual retained bound is
`1.9999999998354667e-06`. The point correctly remains `resolved=False` under
the unchanged `1e-6` acceptance threshold. This assertion assumes its intended
decimal evidence shift is an exact lower bound on the computed gap.

Remote outcome: 1 failed, 1321 passed, 17 skipped, 15 existing Rasterio warnings;
1399.01s. Static gates and fast smoke passed; downstream container HTTP smoke
was skipped because the test job failed. The same committed source had passed
the full local macOS suite, so cross-platform verification is not yet complete.

## Expected repair and acceptance

Make the test assert the bound from actual retained adjacent gaps (and the
prescribed rounding floor), while retaining the unresolved decision, evidence
retention, highest-order identity and an explicit bound above 1e-6. Demonstrate
the finite rounding case without weakening production arithmetic or tolerances.
Run focused tests, mandatory smoke and CI gates; review the scoped test-only diff
and obtain a passing remote CI run. No sampler study, additional source data,
GPU provisioning or generator changes belong to this repair.
