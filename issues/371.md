## Body

## Trigger

The frozen global-modeling plan and #331 require no more than 5% relative MAE degradation in “adequately powered prespecified regional/rare strata.” The repository defines neither which strata are prespecified for this gate nor what makes one adequately powered. PR #370 therefore reports this item as `not_evaluated` instead of inventing a threshold after seeing B1G.

## Scientific objective

Define, before inspecting candidate-versus-baseline subgroup outcomes, which regional and rare-count strata can resolve the 5% noninferiority margin and which must remain inconclusive.

This rule must measure information in independent evaluation units rather than treating survey rows, posterior draws, repeated seeds, or overlapping cohorts as independent evidence.

## Measurable output and acceptance evidence

Produce a versioned decision note that specifies:

- the exact prespecified regional and rare-count strata;
- the independent resampling/analysis unit for each stratum;
- a power or precision criterion tied to the frozen 5% relative-MAE margin, including the near-zero-baseline error case;
- how dependency links, shared cohorts, unequal denominators, and matched-coverage exclusions reduce usable information;
- the output states `evaluable`, `underpowered`, and `not_applicable`, with underpowered evidence remaining inconclusive;
- a sealed simulation or analytical calibration showing the rule's error behavior before it is applied to B1G or another challenger.

The decision note must be reviewed by a spatial statistician. It may not be tuned using B1G subgroup score or error differences.

## Engineering component and public interface

After the scientific rule is accepted, add a pure validation function that consumes only frozen split/dependency metadata and the prespecified stratum definitions, returns the evaluability state and evidence for every stratum, and plugs into the existing paired-benchmark report. It must not read files, fit models, or make an automatic promotion decision.

## Assumptions and refusal conditions

- Do not use row count alone as statistical power.
- Do not count posterior draws, seeds, or duplicated/linked surveys as independent units.
- Do not drop underpowered strata or treat them as passing.
- Do not set the threshold after reading B1G, B2, or future challenger subgroup outcomes.
- If the current five geographic outer blocks cannot resolve the margin, return `underpowered`; the candidate remains inconclusive on this gate.

## Downstream consumers

#331 uses this rule for its frozen subgroup noninferiority gate. #189 uses the same contract for later challengers. This issue does not change the 5% margin or authorize model promotion.
