## Observed issue

The final review of `feat/global-af-b0h-runner` at `e20aed4` found a nonblocking
performance problem in `genomeos/validation/heterogeneity_runner_store.py:424`.
Its object-reachability check scans completions for each object because the
correlated `IN` expression does not use the existing keys as independent lookups.
This check runs in completion publication/reuse and uncertain readback.

On the pinned local SQLite runtime, a synthetic in-memory SELECT took
0.04629525006748736s at1,000 completions/3,000 objects and
1.7012772919842973s at6,000 completions/18,000 objects. Both returned zero
orphans. `EXPLAIN QUERY PLAN` showed an object scan and a correlated completions
scan. These are single-query observations, **not** full-campaign throughput,
disk performance or GPU-capacity measurements. No science was run. The synthetic
rows were not codec-valid and foreign keys were not enabled for this diagnostic.

```sql
SELECT count(*) FROM objects o WHERE NOT EXISTS (
 SELECT 1 FROM campaign c WHERE o.digest IN (c.manifest,c.admission,c.null_reference))
AND NOT EXISTS (SELECT 1 FROM starts s WHERE o.digest=s.digest)
AND NOT EXISTS (SELECT 1 FROM completions c WHERE o.digest IN
 (c.start_digest,c.digest,c.receipt,c.failure))
AND NOT EXISTS (SELECT 1 FROM losses l WHERE o.digest IN (l.start_digest,l.digest))
```

## Proposed bounded follow-up

Preserve the exact NULL-safe reachability/refusal semantics while making the
check indexable or collecting a bounded referenced-digest set. Do not change
the schema, publication policy, loss classification, evidence bytes or science.

Acceptance should include semantic parity for NULL references, valid roots,
orphan objects and corrupt publication/loss relations; retain existing reuse and
uncertain-readback tests. Inspect query plans and measure scaling across fixed
row counts without a flaky wall-time assertion. Report actual campaign storage
timing separately if it becomes available.

Safe to defer; not a prerequisite for the first frozen calibration. No integrity
violation was found and no fix is implemented. Advances the execution-efficiency
work supporting #211/#189. Four-part contract: retain scientifically identical
evidence; demonstrate semantic parity and measured scaling; modify only the
concrete publication audit interface; refuse corruption exactly as before,
without interpreting synthetic microbenchmarks as campaign guarantees.
