## Body

## Objective

Publish the existing GenomeOS API/read-path container in GitHub Container Registry so releases are discoverable from the repository and can be pulled without rebuilding locally.

## Acceptance evidence

- `ghcr.io/bschilder/genomeos:latest` resolves from GHCR.
- The same image is available under an immutable Git-commit tag.
- The manifest supports `linux/amd64` and `linux/arm64`.
- The OCI source label associates the package with this repository.
- A pulled image passes the existing `/ready` HTTP smoke contract.

## Engineering interface

The root `Dockerfile` remains the build contract. GHCR is the distribution adapter; runtime configuration continues through `DATABASE_URL`, `ATLAS_ARTIFACT_ROOT`, and the existing read-path settings documented in `docs/deployment-gcp.md`.

## Assumptions and refusal conditions

- This publishes application code plus the tiny synthetic diagnostic artifacts already included by the Dockerfile; it does not publish restricted scientific source data or immutable production surface artifacts.
- Do not publish if the tracked-file privacy gate fails, the image build fails, or GHCR authentication lacks package-write permission.
- The image is a backend deployment artifact and is separate from the GitHub Pages website release.

## Downstream consumers

Cloud Run deployments, local integration environments, and collaborators evaluating the versioned API container.
