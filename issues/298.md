## Body

## TL;DR

The test covering our prior-normalization review figure only checks that a picture file was created
and is bigger than 10 kB. It would still pass if the two map panels were swapped, if latitude and
longitude were exchanged in a plot call, or if a colour scale were reversed — all of which would
change what the figure means to anyone looking at it.

Found while reviewing #288, which is otherwise correct and is merged. This is about the safety net,
not that change.

---

## What is covered, and what is not

`tests/test_plot_prior_normalization.py` has two tests doing very uneven work.

**The computation is well covered.** `test_conditional_counterexample_matches_the_authored_numeric_control`
checks the retained-observation count, that model locations are collocated with their cells to within
a millionth of a degree, an exact local-ratio control of 1.0, a bounded correlation and false-support
count, the control-unknown flags, and determinism under reversed input order. A broken great-circle
distance, a swapped coordinate order in site selection, or any row-order dependency would fail it.

**The drawing is not covered at all.** `test_prior_normalization_figure_is_created_standalone`
asserts only that the render call returns the path it was given and that the file exceeds 10,000
bytes. Nothing connects a computed array to the panel it belongs in.

## Why it matters here specifically

Review figures in this project carry invariants, not just aesthetics: measured observations and
inferred surfaces must never read as one layer, absent data must be visible rather than blank, and a
colour ramp must read low-to-high without its legend. A reversed ramp inverts the meaning of a map
for anyone who only glances at it. None of that is currently enforced by a test — it was verified by
a human looking at the rendered image, which does not survive the next edit.

## Suggested fix

Assert on the figure object rather than the file. Matplotlib lets you inspect axes after rendering,
so a test can check that the first panel's scatter data match the distance array, that the second
panel's match the ratio array, that each mappable's normalisation runs in the direction intended,
and that the two point layers are distinguishable. That is a handful of assertions and it closes the
whole class.

## Also, a small naming imprecision

`scripts/plot_prior_normalization.py` picks its reference point as the retained survey nearest
`(5.0, 20.0)`, described in a comment as "the retained survey nearest the regional centre". The
region's actual centroid is `(5.0, 24.0)`. Any fixed point makes the demonstration's argument, so
nothing is wrong with the figure — the comment just names the wrong thing, by about four degrees of
longitude.
