## Body

Observed while executing the predeclared development reference-count benchmark for #189 on feat/global-af-reference-counts at fabbf53. Of the first four seed-42 configurations, two completed and two exited 2 with `randomized_pit values must be finite and between 0 and 1`. Two invalid values per failing configuration exceeded 1 by approximately 4e-13 and 5.5e-13. Remaining eight runs were halted, not silently dropped; original attempts and unchanged input protocol are retained locally. No source rows or participant data are attached.

The point-mass path uses stable finite products, while the beta-binomial CDF sums log-beta differences and switches to a complementary tail only when the computed log sum reaches zero. The suspect near-one prefix and point mass are numerically inconsistent. A synthetic independent reproduction and exact/high-precision reference are required before implementation; clipping probabilities or weakening benchmark bounds is not an acceptable fix.

A second boundary failure compounds this: predictive_diagnostics returns the invalid PIT, so the per-fold try block marks that fold completed. Global summarize_benchmark rejects it outside the per-fold handler, before artifact creation. Numerical failures must remain explicit failed-fold outcomes with all planned rows and other successful folds retained.
