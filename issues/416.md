## Body

**Reported on genome-os.org /app/:** Cesium's raw dialog appeared: 'An error occurred while rendering. Rendering has stopped. TypeError: Failed to fetch dynamically imported module: https://genome-os.org/cesium/Workers/createPolygonGeometry.js'. The globe stayed dead until the page was reloaded.

**Root cause.**
- A single transient network failure while any of Cesium's web workers imports a module makes a frame throw. Each worker thread fetches the module separately, 11 times on a default load.
- The app never handled render-loop errors: it had no `renderError` handling, and `showRenderLoopErrors` and the default render loop were left on. Cesium therefore shows its own panel and stops rendering permanently.
- Cesium's geometry workers are created once per page and keep a failed import, so recovering in place is impossible; recovery needs a reload.
- **Reproduced 100%:** abort only the first request for `createPolygonGeometry.js` on the old build. Every file in the live worker import graph (36) loads fine, so the trigger was a transient fetch failure, not a missing deploy file.

**Also found:** users with the OS reduce-motion setting got the globe built twice on load, including a second 3 MB Natural Earth download.

**Scope note:** the Part B build (#405) never loads `createPolygonGeometry.js`, and survives a single failed fetch of each of its remaining Cesium worker modules. It still needs the same render-error handling, which it takes on when rebased onto main.
