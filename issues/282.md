## Authorized scientific and product contract

The user approved implementation on 2026-09-14: modular trait–variant evidence, geographic comparison, and rigorously gated cross-trait / gene-pleiotropy assessment. No substitute datasets, invented metadata, demo production data, or fallback methods.

- Claim: expose exactly what registered studies and immutable geographic artifacts support; absence from a selective index is not absence of association.
- Output: versioned evidence contracts, bounded evidence browser, executable source audit, independently labelled synchronized maps, and explicit blockers for unsupported analyses.
- Interfaces: pure domain contracts/policy; separate SQL/read adapters and audit CLI; existing Cesium renderer; no inference on a serving path.
- Refusals: missing verified identities/counting orientation, source provenance, complete summary statistics, matched LD, overlap handling, gene attribution, or validated protocol prevent corresponding scientific claims. No clinical inference from a map.

## Delivery checklist

- [ ] Freeze contracts and document module boundaries and acceptance tests.
- [ ] Audit actual registered inputs without auto-seeding a database.
- [ ] Expose bounded trait ↔ variant evidence with explicit selective-index coverage and QC unknowns.
- [ ] Compare real geographic artifacts with synchronized navigation and separate legends/masks.
- [ ] Qualify complete GWAS/LD inputs and validate cross-trait protocols against independent benchmarks.
- [ ] Validate gene attribution and pleiotropy evidence dossiers.

The local database currently has zero phenotypes, associations, and releases. No numerical genetic-correlation, colocalization, or pleiotropy result can be produced from it. Existing Atlas maps can support visual juxtaposition, not an inferred trait correlation. This issue remains open until the scientific milestones are actually met.
