## Body

## Scientific objective

Implement the planned WP4 **B1 local count smoother** as an offline comparator for the HbS background/peak failure documented in #103 and the broader global AF program in #189. The model should answer whether local count evidence plus explicit refusal can preserve endemic peaks and suppress unsupported non-endemic background without the global probability-mass transfers rejected by #305 and #306.

This is a baseline/comparator task, not a claim that local smoothing is the production model. It must remain source-neutral. MAP count-bearing HbS observations may instantiate the benchmark; MAP malaria-risk, EVI, friction, and other environmental products receive no priority and are out of scope.

## Measurable output and acceptance evidence

Use the frozen Piel-comparable HbS count artifact and immutable split identities. Report:

- normalized held-out count log probability under the declared observation law;
- predictive calibration and interval width where the smoother defines a predictive distribution;
- whole-cohort and geographic/spatial-buffer folds, retaining every refusal and failed fold;
- zero/positive, denominator, distance-to-training-support, endemic-peak, and non-endemic-background strata;
- requested versus emitted cells and excluded fraction;
- the unchanged B0 constant comparator and frozen B2/current-model evidence where directly comparable;
- supported-only HbAS/HbSS parity only after count gates pass, never as a tuning target.

Tune bandwidth/support only inside training folds. A useful B1 comparator must improve on B0 count prediction and expose where it refuses. Promotion beyond comparator status additionally requires no material regional/positive-count regression and independent confirmation. Returning `unknown` outside justified support is valid; manufacturing global coverage is failure.

## Engineering component and public interface

Build a pure offline science module with an explicit typed interface accepting reviewed count observations, spherical coordinates/footprints, fold-local configuration, and query locations. It returns predictive count/frequency summaries plus support/refusal metadata. File/network/HTTP access, artifact writing, rendering, and orchestration remain separate adapters.

The implementation should begin with the smallest prespecified local count model that can test the claim. Candidate bandwidths and kernel/support choices must be finite and declared before outcome inspection. Use vectorized distance/count reductions or bounded neighbor queries; do not implement observation-by-query nested Python loops. Reuse the existing grouped/spatial fold and exact count-scoring contracts rather than create incompatible metrics.

## Assumptions, refusal conditions, and downstream consumers

- Observed zeros remain count outcomes, not structural-absence labels.
- Missing coordinates, reviewed uncertainty radii, cohort IDs, sampling design, or ascertainment are hard refusals.
- Whole cohorts stay intact; spatial-buffer exclusions and source dependencies remain explicit.
- Footprint/radius assumptions are reported and compared where required by WP2; point coordinates are not silently treated as exact recruitment support.
- No environmental/pathogen covariate enters this comparator.
- No inference enters the serving path, and no output is publication eligible until the existing golden and independent-validation gates pass.
- Downstream consumers are #103, #45, and #189. Expert review should focus on the local likelihood/uncertainty semantics, support boundary, bandwidth selection, and whether the comparator remains fair to B0/B2.

## Context

- #301 aligns the 2010 burden denominator and records the canonical fit/parity result.
- #305 rejects the reconstructed Piel flexible link at the current failure operating point.
- #306 rejects a global zero-inflated beta-binomial before a spatial fit: held-out cohort-macro score worsens and positive counts regress.
- The global modeling plan names `B1 local smoother and regularized covariate regression`; this issue covers only the local count-smoother component. Covariate regression remains a separate, gated comparison.
