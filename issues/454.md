## Body

## Goal

The website is text-heavy. Make it visual: each concept gets an animated, interactive, thematically relevant graphic with minimal supporting text, across every page. The design should look professional and clean, as if made by an expert graphic designer.

## Scope

- **Merge Working groups into Contribute.** Working groups becomes a section of Contribute. Remove the redundancy between the two and condense the text. `/working-groups/` redirects to the new section, so existing links keep working.
- **Rename "Technical docs" to "Docs"** in the header and wherever else the label appears.
- **Every page goes visual-first:** Home, Project, Contribute and the Docs landing. Privacy and 404 get the same visual language.
  - Privacy keeps every required disclosure.
  - The docs content stays reference text.
- **Scientific accuracy holds in the graphics.** Measured observations and inferred surfaces stay visually distinct, uncertainty is shown honestly, and nothing overclaims.

## Approach

1. Audit the current pages: words per section, redundancy, existing visuals, and the tests that pin copy.
2. Run a design panel of three directions with working prototypes. Judge them on design quality, science communication and engineering, then synthesize one spec and copy deck.
3. Build a foundation first (tokens, a shared graphics and motion kit, nav), then the pages in parallel.
4. Review with screenshots, axe, a reduced-motion check and a performance budget, and enforce a word budget per page.
5. Use hand-authored SVG, CSS and small TypeScript islands, with no heavy animation libraries unless their byte cost is justified. Respect `prefers-reduced-motion`. Every graphic needs a text alternative.

## Acceptance

- The nav reads Project · Contribute · Docs · GitHub, plus the Atlas button. `/working-groups/` redirects.
- Every page's word count drops substantially against today, enforced by a test, and every concept section carries a graphic.
- WCAG AA contrast, keyboard access and screen-reader alternatives. The axe tests pass, and reduced motion is honoured.
- The site meets the per-page JS and LCP budgets on desktop and phone.
- Before and after screenshots, desktop and phone, are attached to the PR.
