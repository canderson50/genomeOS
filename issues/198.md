## Body

## Scientific objective and observed limitation

Clarify reproducibility across the trusted `SurfaceFit` cache boundary (design §§5–7),
without silently relaxing numerical tolerances or changing an existing model. Discovered
while implementing #191; it is present at parent `6692d1e`, not introduced by the
configuration extraction at `c74b617`.

The same freshly fitted synthetic HSGP object and its reloaded pickle produce slightly
different latent/surface arrays. Repeated predictions from a loaded object are bitwise
identical, and loading the same pickle under the original versus extracted implementation
is bitwise identical. Thus fresh-versus-loaded execution, not this class move, is the
currently isolated difference. Recompilation is a hypothesis, not an established cause.

## Reproduction

Use a checkout of `6692d1e17eb63f9576a8893d8bf4ef67a9a0c8a6`, the existing test fixture,
and a new temporary directory. No real genotype data or untrusted pickle is needed.
In the recorded environment: Python 3.12.13 macOS arm64; PyMC 6.3.1, PyTensor 3.3.0,
NumPy 2.4.6, SciPy 1.18.1, JAX/JAXlib 0.11.1, NumPyro 0.21.0.
Run `scripts/env_report.py` before comparing another environment.

First process, given a new existing temporary directory as argv[1]:

```python
import runpy
import sys
from pathlib import Path
import numpy as np

fixture = runpy.run_path("tests/test_surface_fit.py")
fitted = fixture["fit_surface"](fixture["_observations"](), fixture["FAST_CONFIG"])
lat, lon, an = [0.0, 5.0], [-8.0, 8.0], [200, 200]
directory = Path(sys.argv[1])
numeric = directory / "legacy-before.npz"
cached = directory / "legacy-before.pkl"
if numeric.exists() or cached.exists():
    raise RuntimeError("legacy evidence must not be overwritten")
np.savez(
    numeric,
    latent=fitted.predict_draws(lat, lon),
    surface=fitted.predict(lat, lon).to_numpy(),
    survey=fitted.predict_observation(lat, lon, an).to_numpy(),
    prior_frequency_sd=fitted.prior_frequency_sd,
)
fixture["save_fit"](fitted, cached)
```

Second clean process, the same directory argument and unchanged source/environment:

```python
import sys
from pathlib import Path
import numpy as np
from genomeos.surfaces.fit import load_fit

directory = Path(sys.argv[1])
reference = np.load(directory / "legacy-before.npz")
fitted = load_fit(directory / "legacy-before.pkl")
lat, lon, an = [0.0, 5.0], [-8.0, 8.0], [200, 200]
actual = {
    "latent": fitted.predict_draws(lat, lon),
    "surface": fitted.predict(lat, lon).to_numpy(),
    "survey": fitted.predict_observation(lat, lon, an).to_numpy(),
}
for name, right in actual.items():
    print(name, np.array_equal(reference[name], right), np.max(np.abs(reference[name] - right)))
```

same-process round trip is a different diagnostic.

## Acceptance and refusal conditions

Identify the cause and define/test the cache replay guarantee in the pinned environment.
Test fresh/reloaded and repeated/reordered calls separately. Preserve any meaningful
precision/graph difference rather than rounding predictions to manufacture equality.
Keep cached-parent/cached-new and fresh-parent/fresh-new as separate exact version-
compatibility controls for #191. Do not broaden the configuration-only refactor to fix
an uncharacterized numerical issue, change priors/convergence rules, or relabel the cache
as an archival scientific artifact. Precomputed published artifacts remain immutable.
