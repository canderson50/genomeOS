## Body

## TL;DR

License the genomeOS source code and documentation under Apache License 2.0 and put trustworthy project badges at the top of the README. The badges show the license, Python package version, measured test coverage, CI status, and published Docker package version.

## Decision

The repository owner explicitly selected Apache License 2.0 on 2026-09-22. No further human licensing decision is required for this task.

## Acceptance evidence

- A root `LICENSE` exactly matches the Apache Software Foundation's canonical Apache License 2.0 text.
- `pyproject.toml` declares the PEP 639 SPDX expression `Apache-2.0` and includes `LICENSE` in distributions.
- The README license badge links to the full license, and the License section distinguishes project-authored work from third-party data and assets.
- README badges identify package version, measured code coverage, CI status, and the Docker package version, with useful links.
- Coverage is measured locally by `pytest-cov`; no coverage report is sent to an external coverage service. CI regenerates the repository-hosted SVG and rejects a stale percentage.
- The container workflow publishes the version from `pyproject.toml` alongside `latest` and the immutable source-SHA tag.
- Built source and wheel distributions include the license metadata/file.
- Repository smoke, packaging, privacy, and test checks pass.

## Scope and consumers

This is a repository-wide governance, packaging, and project-status change, so no single P0–P5 label applies. It changes no scientific method, data reuse determination, or source-specific restriction. Consumers are contributors, package installers, downstream redistributors, automated license scanners, and readers assessing project health.
