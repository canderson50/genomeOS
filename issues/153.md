## Body

## Product claim

A newcomer can understand why genomeOS exists, distinguish measured data from modeled estimates, find the working group that matches their skills, and reach a well-specified contribution task without reading the technical repository first.

## Measurable output and acceptance evidence

- A public, static Astro/Starlight site deployed by GitHub Actions to GitHub Pages.
- Custom pages for Home, Project, Working groups, and Contribute, plus a searchable technical-docs area.
- The visual system follows the existing `docs/images/genomeos-banner.png` “orbital observatory” direction and remains usable on mobile, by keyboard, with reduced motion, and at accessible contrast.
- The global header and footer link to this repository with a labeled GitHub icon.
- Data, Modeling, and Product & Experience working groups are described with concrete work and entry points. Modeling includes Bayesian spatial methods, geometric deep learning, uncertainty quantification, validation, and other defensible approaches.
- GitHub Issues and Projects guidance explains labels, statuses, `Ready`, issue-author notification, pull requests, and expert review.
- AI chat and personal-genome upload are marked as unbuilt future directions requiring privacy, governance, and scientific review.
- The build is reproducible from a pinned Node version, exact package lock, and `npm ci`; PRs build without deploying and `main` deploys the tested artifact.
- Links, production base paths, metadata, social image, sitemap, and generated HTML pass automated checks.
- `genome-os.org` is the canonical URL once DNS and GitHub domain verification are complete; the site documents the required GoDaddy handoff.

## Engineering component and public interface

An isolated `website/` Node project using Astro and Starlight, plus `.github/workflows/pages.yml`. Public routes are `/`, `/project/`, `/working-groups/`, `/contribute/`, and `/docs/`, served at `https://genome-os.org/` with the GitHub Pages URL as the deployment fallback.

## Assumptions and refusal conditions

- This release is informational and static. It collects no analytics, accounts, chat messages, uploads, or genetic data.
- Current capabilities and future directions must be visibly distinguished; the site must not imply the diagnostic preview is a scientific product.
- Published observations and inferred surfaces remain distinct in every explanation and visual.
- Sensitive features do not become commitments merely because they appear in organizer notes.
- Existing repository docs remain authoritative for detailed engineering contracts; public summaries link to them rather than silently changing scientific policy.

## Downstream consumers

Prospective contributors, working-group organizers, scientific reviewers, partner organizations, and later P5/P12 product documentation.
