## Summary

Publish an **evidence-shape audit** of the G6PD survey layer: a small diagnostic that measures how the male-observation weight is distributed across studies and countries, so that a parity comparison to Howes can state what it is actually testing.

This is not more curation and it proposes no change to the adapter or to any committed data. It measures the input the parity test will be judged against. Proposal for triage; happy to close if it is not a fit.

## Why it fits the project

1. `map_g6pd.py` already decides the hard part and argues it well: males only because they are hemizygous, so `ac = number_males_deficient` over `an = number_males` needs no assumption; females excluded with a stated reason; administrative centroids recovered from country polygons; refusals counted rather than dropped. That decision is taken as given here and not re-litigated.
2. What no existing artifact records is the **shape** of the evidence. A layer whose weight is concentrated in a few studies is a different input from one spread evenly, even when both add to the same total. Two layers can pass the same parity threshold while supporting very different claims.
3. The project's own position is that evidence strength is exposed rather than hidden (discussions #1 and #2). Study concentration and per-country citation depth are evidence-strength facts.

## Evidence (run 2026-10-08 on the published export, 1,749 rows)

Fetched with the repository's own tool (`scripts/fetch_map_hbs.py --layer g6pd`: 416,612 bytes).

| Measure | Value |
|---|---|
| Rows with a male denominator | 910 |
| Rows with a female denominator | 336 (both sexes 324) |
| Metadata-only rows, no counts | 827 |
| Total males sampled | 316,448 |
| Total females sampled, i.e. the weight the current adapter leaves unused | 106,510 |
| Distinct citations | 270 (254 contributing a male denominator) |
| **Gini across contributing studies** | **0.736** |
| Share of all male observations held by the five largest studies | 32.7% |
| Largest single study | 1 row, 35,714 males, 11.3% (Singapore) |
| Distinct countries | 95 |
| **Countries whose entire male evidence is one citation** | **48 of 95** |
| Internal inconsistencies (deficient > sampled, zero males, missing coordinate, missing citation) | 0 |
| Rows where the `sexes` label disagrees with the count columns | 0 |

Three readings:

- **The pooled total is dominated by a minority of studies.** At Gini 0.736 a pooled comparison and a per-study comparison answer different questions.
- **48 of 95 countries rest on one citation.** In those, agreement between the layer and a reference tests that study rather than the layer's handling of the country. The 47 multi-citation countries are where the machinery can actually be tested.
- **Four of the five largest contributing studies are a single row covering a whole country** (Italy, Japan, Singapore). A country-scale frequency resting on one survey is not an error, but it is one measurement, not independent confirmation of a model.

Two of these are confirmations rather than problems: the layer is internally consistent on 1,749 of 1,749 rows, and the `sexes` label agrees with the counts everywhere, which verifies the adapter's choice to read the counts rather than the label.

## Proposed scope

- Add the diagnostic as a read-only report over the fetched export: no data written, no artifact changed, no frequency asserted.
- Record in the G6PD work that per-country parity claims are single-study claims in 48 of 95 countries, so a country-level comparison is not read as independent validation where it is not.
- Optional follow-up, not part of this: a per-study weight or clustering rule for the pooled fit, if the leverage finding is judged material. That is a modelling decision and yours.

## What this explicitly does not do

No change to `map_g6pd.py`, to the female-exclusion decision, to any committed payload, or to the parity tolerances. It asserts no allele frequency. It does not propose that the layer is wrong: the layer is consistent, and this documents the shape of its evidence.
