## Body

## TL;DR

Trained models (fitted surfaces) can't go into the public data store yet, because they exist only as pickles. Export them to a format that is safe to load from the internet, then publish them.

## Why

The owner wants trained models available to everyone. Today `genomeos.surfaces.persistence.save_fit` writes `*.fit.pkl`: a pickle of the PyMC graph plus the posterior (`FIT_FORMAT = 2`). Unpickling a downloaded file executes whatever code it contains, so the data-store builder refuses pickles outright (#468, data store design 2026-10-17 §8, call C11). They are also tied to the installed PyMC and pytensor versions.

Where the fits are today:

- Local, git-ignored, under `data/store/{fits,screen,screen_v2}`.
- The interim Hugging Face mirror (`scripts/sync_store.py`): `store/fits` holds 2 pickles (about 217 MB), `store/screen` holds 20 and `store/screen_v2` holds 28. That is about 0.7 GB in all. These are publicly downloadable today, and the dataset card carries a "only load files you trust" warning.

## Proposed scope

1. Add an export with no pickle anywhere in it:
   - the posterior `InferenceData` as netCDF (ArviZ);
   - a JSON document for `FitConfig`, the design levels, `correlation_range_km`, the centre and scale, and the format version;
   - npz with `allow_pickle=False` for any prediction state, such as the inducing points.
2. Add a loader that rebuilds the model from code plus that config and never unpickles.
3. Add a round-trip test: predictions from the exported fit equal the pickle path's. Note the known fresh-versus-cached drift in #198.
4. Publish the exported fits in a data-store release, under a path such as `models/`, with source terms carried as for artifacts.
5. Once a safe copy exists, decide whether the public HF mirror should keep serving the pickles.

Until then, the parquet artifacts carry every per-cell posterior summary a consumer needs.
