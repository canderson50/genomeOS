## Body

The site header shows a text-only "genomeOS" wordmark and the browser tab uses a placeholder ring icon. Replace both with the genomeOS Foundation artwork (dark, transparent SVG).

**Requested by the owner**
- Use the dark transparent SVG logo across the site (header and footer).
- Show "FOUNDATION" under genomeOS in the header: larger when the page first loads, shrinking a bit as the reader scrolls.
- A favicon made from the "OS" part of the logo. The first version, the whole "OS", was too small in a 16 px tab, so the owner chose the globe "O" alone, on a dark circle so it shows on light tab bars too.

- Rebrand the "Launch Atlas" header button as **genomeOS Atlas**: still eye-catching, but in keeping with the dark site. A black button with an animated aurora effect coming from its edges. From three live variants the owner chose **Northern lights**: green, cyan and violet curtains that drift and spill past the edges. The label is the globe mark, the name and an arrow; on phones, the globe mark alone.

**Done when**
- The header lockup (genome + OS + FOUNDATION, no tagline) is cropped from the owner's file with every path byte-identical. It is larger at the top and compact after scrolling, does not flicker at the threshold, and respects reduced motion.
- `/app/` keeps the compact wordmark and its current header height, so the globe keeps its space.
- The favicon set (SVG, 16/32/48 PNG, ICO, apple-touch-icon) is linked on every page, including docs and `/app/polygon/`.
- Nothing overflows sideways at 320–1440 px, the build passes the link checks for both base paths, and tests pin the crops, sizes and behaviour.
- The header button reads "genomeOS Atlas" (accessible name included) with the Northern lights aurora. It holds still under reduced motion, stays legible in forced colours, works from the keyboard, and the Menu's Atlas link uses the same name.
