## Problem

The launched documentation site has three small but site-wide presentation inconsistencies:

1. The homepage says “Place matters…” where “Location matters…” is clearer.
2. Visible prose uses a neutral body face for `genomeOS`, while the navigation wordmark uses the project’s distinctive Raleway treatment.
3. The navigation scrolls out of view, making movement between the project, preview, working groups, contribution guide, and technical docs unnecessarily difficult on long pages.

## Acceptance evidence

- The homepage sentence begins “Location matters because a genetic variant…”
- Every visible `genomeOS` project-name token uses the shared wordmark typography; URLs, metadata, code, and accessibility text are not rewritten.
- The public navigation remains fixed to the top of the viewport while scrolling.
- After a small scroll threshold, the navigation condenses vertically without making link text smaller than the established minimum.
- Reduced-motion visitors retain sticky navigation without the animated compact-state transition.
- Desktop and mobile browser tests cover persistence, compaction, typography, accessibility, and horizontal overflow.

## Scope

Follow-up to #153 and PR #155. This is presentation and navigation behavior only; it does not change scientific content or application behavior.
