## Body

## Scientific objective

Implement the next owner-authorized #189 WP2/WP4 ablation: test whether explicit between-population variation improves held-out reference-panel count prediction beyond pooled B0, while integrating uncertainty in both mean and dispersion. Name it B0H; it does not replace the planned spatial B1/B2 models.

## Measurable output and acceptance evidence

A pure training-only beta-binomial population model with independently parameterized variants, strict sampler diagnostics and marginal predictions through the existing CountPredictive contract. Before real comparison: hand/independent quadrature checks, allele-complement symmetry, train/test leakage tests, missing-denominator accounting, actual NUTS fits, prior simulation calibration, homogeneous and structured/misspecified simulation controls. Then paired evaluation on the unchanged twelve-run development matrix from PR #210, retaining all failures and one declared doubled-budget retry.

No geography, latent-frequency truth, independent-locus replication, external confirmation, global improvement or release claim follows from this within-resource experiment. Existing promotion defaults and golden tests remain unchanged.

## Engineering component and interface

Separate fit(training ReferenceCount rows, explicit config) from predict(fitted parameters, withheld ReferenceCount rows, explicit CDF backend). Reuse the existing reference-count runner and count diagnostics, preserving B0 compatibility and binding model/seed/retry/source provenance to new immutable research artifacts. PyMC/NumPyro is the existing inference engine; no new dependency or CuGen prerequisite.

## Assumptions and refusals

For each variant independently: mean ~ Beta(1,1), rho ~ Beta(1,9), concentration=(1-rho)/rho, and population counts ~ BetaBinomial(AN, mean*concentration, (1-mean)*concentration). A fixed Beta(1,4) rho-prior sensitivity is reported separately; neither is a prior estimated from these linked loci or a claim about historical FST. This is a working population-exchangeability model, not resident representativeness or joint LD inference.

Refuse missing training variants, invalid/misaligned arrays, unsupported numeric domains, divergence, R-hat above1.05, or bulk/tail ESS below200. Never clip, drop difficult variants, loosen convergence gates, or use held-out counts in fitting. AN0 stays unavailable. One logged retry doubles tuning/draws without changing model, observations or acceptance rules.

The owner explicitly asked to continue implementation without waiting for routine design approval. This issue scopes that existing authorized program; it is not an unrequested product feature. Expert review should check the prior interpretation, count-calibration target and distinction between computational vectorization and independent genetic evidence.
