## Observed defect

Final whole-branch review of the owner-authorized #211 diagnostic adapter found
that `SelectedSbcQuantities` accepts Boolean and float point-slot identifiers.
At commit3d739114559e7a845424712e74bd2832d3a98b6e,
`genomeos/validation/heterogeneity_sbc_quantity_types.py:353` checks tuple type
and equality with the canonical map but not individual scalar domains.

The reviewer ran one bounded probe using the existing synthetic accepted-fit
fixture and mocked reference. These public constructor replacements all
succeeded, retained the invalid types and retained `complete=True`:

```python
replace(result, point_slots=(False, *range(1, 13)))
replace(result, point_slots=tuple(float(i) for i in range(13)))
replace(result, point_slots=(np.bool_(False), *range(1, 13)))
```

Expected: reject Boolean and float identifiers, including numerically equal
ones. Normalize supported Python/NumPy integers through existing public
`simulation_integer`, check the exact canonical map, retain Python integers.

## Scientific and engineering contract

This violates fail-closed typed/canonical evidence validation (Atlas design
§§7–8,12), not an observed executed-rank error: orchestration already emits
integer slots. The smallest correction is at the enclosing constructor, with
regressions on both thirteen-point complete and nine-point failed-control maps.
Include supported NumPy-integer acceptance/normalization. No numerical method,
seed, threshold, retry, denominator or source provenance change is authorized.

Acceptance: actual regression RED/GREEN, focused quantity tests and smoke,
scoped re-review of the final fix and final-head full CI gates. No actual
calibration or worldwide allele-frequency gain is claimed. Advances #211/#189.
