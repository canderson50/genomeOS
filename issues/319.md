## Body

## Scientific objective

Make long offline spatial-model comparisons recoverable at fold boundaries so infrastructure interruptions do not erase completed scientific computation or encourage selective reruns. Recovery must preserve the frozen split ledger, inputs, configuration, seeds, code identity, and exact scoring semantics.

## Measurable output and acceptance evidence

- After each planned fold reaches `completed`, `failed`, or `infeasible`, write an immutable fold artifact and status record before beginning the next fold.
- A controlled interruption after fold 2 followed by resume produces the same final predictions, fold ledger, summary, and manifest hashes as one uninterrupted run, except for explicitly modeled runtime/provenance fields.
- Resume refuses any mismatch in input hashes, split manifest, configuration, seed schedule, code/science-source hashes, backend, or completed-fold artifact integrity.
- Final publication remains atomic: no partial run can be mistaken for a complete comparison, and `comparison_complete` retains its existing meaning.
- Focused interruption/resume tests, full pytest, smoke, Ruff, contract, module-size, and privacy gates pass.

## Engineering component and public interface

Add a versioned checkpoint contract around `genomeos.validation.spatial_gp_benchmark.evaluate_single_variant_gp` and `scripts/benchmark_spatial_gp.py`. Keep the scientific fold function and final artifact schema stable where possible. The CLI may gain an explicit checkpoint/resume path, but no automatic discovery or permissive fallback.

## Assumptions, refusal conditions, and downstream consumers

- A fold is the smallest accepted recovery unit; mid-fit and mid-scoring state are not trusted checkpoints.
- Checkpoints are artifacts, not mutable caches: write to a temporary path, validate, then atomically publish.
- A resumed run may reuse only terminal fold outputs whose expected held-out IDs and all provenance hashes match exactly.
- The five-fold B0/B0H/current-GP ladder and later source-neutral model/covariate comparisons are downstream consumers.

## Observed trigger

The current five-fold A100 run completed at least one fit-and-score cycle but `scripts/benchmark_spatial_gp.py` writes `predictions.tsv`, `fold_status.tsv`, `summary.json`, and `manifest.json` only after `evaluate_single_variant_gp` returns all folds. A pod or process failure therefore discards every completed fold and forces a full rerun.

## Scope boundary

This changes orchestration and artifact durability only. It must not alter model fitting, count-law evaluation, split construction, metrics, source priority, or promotion criteria.
