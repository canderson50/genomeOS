## Body

## Scientific objective

Establish whether the owner's local CuGen can safely provide training-only, pairwise-complete unphased genotype correlations for a bounded multivariant AF experiment. This is an engineering/numerical pilot under WP6 of #189, not a claim of geographic predictive improvement or a decision on the hierarchical model in #128.

The implementation target is `/Users/bschilder/code/cugen`, inspected clean at `03df1688abf52d295bd85d47f1aca6130440b553`, package0.1.7. Do not substitute pg_gpu. The full CuGen preprint was read via Europe PMC; its association/PRS benchmarks do not validate the AF target.

## Measurable outputs and acceptance

- A versioned synthetic source/sample/block identity manifest and immutable output directory.
- Exact independent CPU contingency/co-observed counts and tolerance-qualified r/r2 agreement with CuGen CPU/GPU; every requested/omitted pair reconciled. Monomorphic/insufficient pairs remain explicit missing/refused, not zero correlation.
- Decoded sample-subset calls and recomputed per-variant mean/sum-of-squares/MAF agree with independently computed values; include reordered identities, missing/all-missing calls, padding and boundaries.
- Deliberate leakage test: held-out sample mutation cannot alter training-only LD or subset metadata.
- Complete workflow timing, setup/transfers/conversion/statistics/output cost, memory semantics, exact code/environment/hardware hashes; record failures and no unexpected skips. Synthetic first, no real-genotype upload until source-specific qualification.

## Engineering contract

Thin offline adapter around public `cugen.subset.subset_cugen_file` and `cugen.ld.ld_matrix`. Public external library does file/device work; pure independent statistics/validation remain separate. Explicit stats=(r,r2), ALT sign, pairwise missingness, backend and pair/window budget. No serving-path inference or production model/schema change.

Source inspection establishes mandatory wrapper checks:

1. Exact, nonempty, 1D integer sample indices with unique stable identities; reject Boolean/fractional/duplicate/out-of-range values before CuGen's coercion. Pass an already validated in-memory array, not permissive pickle-bearing NPZ input.
2. Read and validate encoding/version/layout first. The selected LD path requires encoding0; sample-subset code currently checks magic but interprets packed values as encoding0 and writes that encoding without a source-encoding guard. Reject encoding4 or other formats rather than relabeling phased/probabilistic calls.
3. Source/destination must differ; refuse existing destinations. Failed writes never become admitted completed artifacts. Validate full output after execution before writing a completion manifest.
4. Require complete exact gidx/variant/position/orientation mapping; do not inherit LD annotation missing-position=0 behavior.
5. Use explicit expected single-file inputs rather than directory helper's skip-missing/skip-existing behavior. If multiple blocks are requested, require an outcome for every block.
6. Fix memory budgets for variants×selected samples, not just variant chunk count. Supply pinned/pageable mode explicitly and record actual execution; a pinned-allocation fallback must not be mislabeled as a pinned performance result.
7. LD path's diploid hard-call semantics must be explicit. No sex-chromosome, haploid or dosage inference from generic integers. D/D-prime and phased LD are separate future admission decisions.

## Assumptions, refusal conditions and downstream users

Marginal AF does not identify LD. Pairwise-complete correlation need not yield a valid joint covariance matrix. Training-only LD-assisted imputation and new-region extrapolation must be evaluated as different targets. Any downstream use in a joint likelihood needs an additional statistical contract and independent held-out evidence. Existing source terms, no All of Us export, attribution/biocultural notices and publication gates remain binding.

## Current evidence and scope

Twelve selected existing CuGen CPU LD tests passed, zero skips;70Pandas4Warning warnings remain documented. The entire local `cugen/subset.py` and MIT licence were inspected, but sample subsetting was not executed and no GPU LD run occurred. No CuGen checkout edits or dependencies were installed. The new wrapper checks above are planned integration safeguards, not a claim that they already exist.

Implementation is owner-requested under #189, after the active benchmark foundation review/PR gates. Apply all four board label families; request domain review of missingness, orientation and identity contracts. This issue does not close #189 or #128.

Additional read-only boundary inspection at unchanged local CuGen commit `03df1688abf52d295bd85d47f1aca6130440b553` identified details the bounded pilot must account for. These are source observations, not new benchmark results:

1. **Host budget covers the whole source file on the NumPy reference path.** `ld.py:2393-2400` decodes every variant before the public call selects rows at line 2733. A small requested variant set or `max_pairs` does not bound that decode. Use genuinely bounded source blocks and budget full-file decoding plus intermediate arrays.
2. **GPU tiles are not the entire device allocation.** `_load_packed_rows` (`ld.py:1269-1310`) allocates all selected packed rows on-device; tiled work adds to that allocation. Retained result arrays and final concatenation also need host/device budgeting. Do not label tile-only estimates as peak whole-workflow memory.
3. **Record undefined all-missing statistics explicitly.** The subset implementation uses a protected denominator and writes zero stored mean/sum-of-squares/MAF for an all-missing variant (`subset.py:287-301`). The pilot should verify those storage conventions and the missing flag, while retaining a zero-called-samples/undefined-frequency status. A stored zero must not become a biological AF observation.
4. **I/O and precision must be experimentally identifiable.** The subset call returns elapsed seconds, not whether a pinned allocation silently fell back. The first bounded pilot can explicitly use pageable subsetting; pinned-mode timing needs separate execution evidence. `ld_matrix` calls `read_cugen` without an explicit pinned argument, so the isolated pilot process must record/control its reader setting as well. Request explicit precision rather than presenting an auto-selected mode as measured hardware behavior.
5. **The public structural checker is not sufficient admission evidence.** `write.validate_cugen` explicitly does not validate statistics against decoded genotypes. Its inspected checks also do not establish complete gidx-region layout/annotation identity. Retain the issue's stronger independent decoded-data, layout, mapping and count checks.
