## Body

`SurfaceFit.predict` returns a posterior **summary** per cell — `post_median`, `post_mean`,
`post_sd`, `q025/q975`, `q25/q75` — and nothing exposes the draws those summaries were taken
from. Both consumers of the burden path need the draws themselves:

- **`burden.propagate.compute_burden`** takes `frequency_draws` of shape `(n_draws, n_cells)`.
- **`burden.national.national_totals`** (#94) takes the same, and *cannot* be written any other
  way: a national total is a sum over cells within a draw, and the summary of a sum is not a
  function of the summaries of its terms. Medians in particular do not sum — #92 measures this
  as a 4–7% shortfall on Piel et al.'s own national medians, which is exactly the size of error
  that would be read as model failure.

So the two modules that implement §9 are, today, unrunnable against a real fitted surface. The
rollup in #94 is unit-tested against hand-computed draws, and `scripts/national_estimates.py`
carries a `--synthetic` mode for the plumbing, but no committed code can produce the draws for a
real variant.

## What is needed

A public way to get posterior predictive draws at a set of points, e.g.

```python
fit.predict_draws(lat=..., lon=...) -> np.ndarray  # (n_draws, n_points)
```

`predict` already draws them internally (`pm.sample_posterior_predictive(..., var_names=["freq_pred"])`)
and then summarises; this is exposing what is already computed, not new inference. Reaching into
`fit._model` from outside would be importing a private implementation detail, which AGENTS.md
rules out.

Two things worth deciding while implementing it:

- **Memory.** A global res-4 land grid is ~82k cells; at 500 draws that is ~330 MB as float64,
  or 165 MB as float32. A chunked or `float32` option is probably wanted, and the burden path is
  fine with float32.
- **Persistence.** The national rollup, the cell-level burden artifacts and the figures all want
  the same draws, so writing them once to an `.npz`/parquet keyed by `(variant_id, resolution)`
  would avoid re-running posterior prediction three times.

Blocks a real run of #94 and of #45 (golden test 1). Related: #44, #92, #102.
