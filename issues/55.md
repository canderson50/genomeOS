## Body

## Scientific objective / product claim

Provide the P5 explorer shell in which users can move between a global globe, a conventional 2D
map, and an oblique topographic view of human genetic variation while always distinguishing
measured observations, inferred posterior surfaces, uncertainty, and unsupported regions.

This supersedes the original MapLibre/deck.gl renderer decision following the approved 3D-globe
design discussion. It does not change the P0–P4 scientific or serving contracts.

## Measurable output and acceptance evidence

- CesiumJS explorer replaces the diagnostic iframe at `/app/`.
- Smooth mouse, touch, trackpad, and keyboard camera interaction.
- Animated `Globe`, `Map`, and `Perspective` views.
- Dynamic MAP HbS/G6PD entity selection without page reload.
- Posterior estimate and uncertainty metrics.
- Independently togglable observations, surfaces, support, and geographic context.
- Elevation mode renders the active supported metric as topographic height.
- OSM-derived countries, subregions, cities, and roads with visible attribution.
- Cell/observation inspector with interval, support, provenance, and immutable versions.
- Shareable URL state, responsive controls, reduced motion, and explicit failure states.
- Unit, browser, accessibility, visual, and measured performance evidence.

## Engineering component and public interface

- React island within the existing Astro route.
- CesiumJS scene and batched scientific primitives.
- Engine-independent `AtlasDataProvider` with a static Hugging Face implementation now and GCP API
  implementation later.
- Deterministic, allowlisted build-time export of MAP HbS/G6PD browser artifacts.
- Scale-up path through metadata-rich 3D Tiles rather than one Entity per H3 cell.

Full design: `docs/superpowers/specs/2026-09-06-cesium-globe-explorer-design.md`

Implements Atlas design §11 and advances #56, #57, #58, #59, #63, and #64. Burden,
administrative aggregation, and region-selection completion remain in their dedicated issues.

## Assumptions, refusals, and downstream consumers

- Initial public artifacts are limited to approved MAP HbS and G6PD data.
- No posterior fitting or burden inference runs in the browser or serving path.
- Missing radius, support state, coordinate, metric, provenance, or version is a hard failure.
- Unsupported cells are never coerced to zero or given elevation.
- Observations and inferred surfaces remain separate layers.
- No credential enters static output.
- AFND-derived artifacts remain excluded while #66 is unresolved.
- The provider and URL contracts are consumed later by burden, aggregation, region selection,
  conversational analysis, and the GCP artifact service.
