## Body

The Pages `validate` job on `main` for the merge of #408 (run 37804507196) failed. All three phone contexts (Pixel 7, 360×780, 390×844) failed on `tests/atlas-mobile.spec.ts` › 'a one-finger drag at the centre turns the globe', each after 2 retries, with 'Test timeout of 30000ms exceeded'. As a result `build` and `deploy` were skipped, and genome-os.org still serves the pre-#408 layout.

The test does a full `/app/` load plus a 10-step CDP touch drag over the live Cesium canvas. On runners, every move renders through software WebGL. Under the default 30 s test timeout this sits right at the margin: the same job passed on the PR run and failed on the push run. The other globe-touching tests in the same file already set `test.setTimeout(120_000)`.

Fix: give this test the same 120 s budget. It is a test-budget change only; no assertion changes.
