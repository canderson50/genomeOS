## Body

## Scientific objective / invariant

Registry provenance must identify the source actually supporting coordinate
metadata (Atlas §6/§12); a paper title/comment must not name a different work
from its DOI. Found during the authorized #189 WP0 / #21 qualification audit.

## Reproduction and observed result

At `0dcbb2c9449a4201f92fff3283f90a5319402665`, read
`genomeos/registry/sources/hgdp.py:24`:

```python
PROVENANCE = "10.1126/science.1078311"  # Cann et al. 2002, HGDP-CEPH panel
```

The adapter emits that constant into every registry row. The DOI identifies
Rosenberg et al., *Genetic structure of human populations*, Science298:2381–2385,
not the Cann panel letter. [NLM record](https://pubmed.ncbi.nlm.nih.gov/12493913/).
Cann et al., *A human genome diversity cell line panel*, Science296:261–262,
has DOI `10.1126/science.296.5566.261b`.
[NLM record](https://pubmed.ncbi.nlm.nih.gov/11954565/).

This is a metadata mismatch verified from the source line and bibliographic
records, not a claim to have inspected either complete article or established
which source supports every currently supplied coordinate.

## Expected result / acceptance evidence

Inspect the actual coordinate input provenance and make emitted citation and
documentation consistent with that source. Do not blindly replace every row's
DOI with Cann's merely because the existing comment names it; a general panel
citation is not proof of a particular coordinate, radius or recruitment footprint.
Add a focused provenance fixture and preserve exact source/version locators.
No coordinate, radius, resident semantics or existing artifacts change silently.

## Scope and dependencies

Coordinate/radius qualification continues separately under #21. This small
provenance repair does not block B0H calibration, CuGen, or the count comparison.
No code/data/registry/artifact mutation was made when filing this issue.
Open/closed searches for the DOI and HGDP provenance found no duplicate bug.
