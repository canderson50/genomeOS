## What happened

The `container` workflow created by PR #161 completed checkout, QEMU, Buildx, GHCR login, both `linux/amd64` and `linux/arm64` builds, and SBOM/provenance generation. Its first final registry export failed with `permission_denied: read_package`; after repository access was added with the default Read role, attempt 2 reached the same export boundary and correctly reported the narrower `permission_denied: write_package`.

Run: https://github.com/bschilder/genomeOS/actions/runs/34190943100

## Maintainer decision (2026-09-08)

The package should be public so other people can reproduce the service without GitHub authentication. Document both the moving `latest` tag and immutable commit tags in the root README. This supersedes the original private-visibility assumption.

## Expected behavior

After `main` CI succeeds, the repository-scoped `GITHUB_TOKEN` updates both `latest` and immutable `sha-...` tags on `ghcr.io/bschilder/genomeos`. Anyone can pull the published image, while only the `genomeOS` Actions workflow has Write access.

## Acceptance evidence

- Package Actions access grants `bschilder/genomeOS` the Write role, without granting Admin.
- The failed workflow rerun succeeds.
- `latest` and `sha-813edd0` resolve to the new multi-architecture manifest.
- An anonymous pull of the immutable tag passes `scripts/http_smoke.py`.
- The root README documents public latest and immutable-tag runs, port mapping, readiness, and the synthetic-fixture boundary.

## Engineering component and public interface

This combines a package-level Actions access correction, public GHCR visibility, and reproduction documentation for `.github/workflows/docker.yml` and the root `Dockerfile`. The runtime environment contract is unchanged.

## Assumptions, refusals, and downstream consumers

- Do not introduce a long-lived PAT into Actions; continue using the repository-scoped `GITHUB_TOKEN` with `packages: write`.
- Grant the repository Write, not Admin, package access.
- Cloud Run and durable deployments consume immutable GHCR tags.
- Bundled demo artifacts remain synthetic diagnostics and must not be presented as scientific results.
