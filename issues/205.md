## Body

## Scientific objective and affected invariant

Before admitting GPU-computed training-only LD under #195 / #189, establish numerical agreement with independent exact integer co-observed moments. Pinned CuGen's annotated GPU `r`/`r2` path fails the predeclared absolute error budgets (R <= 1e-5, R2 <= 2e-5) on four synthetic near-fixed-allele cases. Do not loosen these budgets or silently recode alleles to make the pilot pass. This is a numerical admission defect, not evidence of a measured AF prediction error.

NVIDIA A100-SXM4-80GB, driver 580.126.16, CUDA runtime 12090 / driver API 13000, CuPy CUDA12x 14.2.0; Python 3.12.3, NumPy 2.4.6, pandas 3.0.5, SciPy 1.18.1, PyArrow 25.0.1. ## Minimal input and public call

Set the three environment controls above before starting Python. With the pinned CuGen import available:

```python
from pathlib import Path
from tempfile import mkdtemp
import numpy as np
import pandas as pd
from cugen.write import write_cugen
from cugen.ld import ld_matrix

n = 3072
calls = np.full((n, 2), 2, dtype=np.uint8)
calls[0, 0] = 1
calls[[1, 2], 1] = 1
path = Path(mkdtemp(prefix="cugen-ld-repro-")) / "synthetic.cugen"
write_cugen(path, calls, gidx=[30, 10], encoding=0)
annotation = pd.DataFrame({"gidx": [30, 10], "CHR": ["1", "1"],
                           "POS": [101, 201], "ID": ["synthetic-0", "synthetic-1"]})
for backend in ("numpy", "gpu"):
    print(backend, ld_matrix(
        path, annotation=annotation, backend=backend, precision="fp32",
        stats=("r", "r2"), sign_reference="alt", missing="pairwise",
        min_obs=2, maf_min=0, min_r2=0, window=None, window_kb=None,
        output_format="pairs", output=None, tile_size=2, max_pairs=21,
        verbose=False))
```

## Localized mechanism, not yet a production fix

At pinned `cugen/ld.py:2078`, `_r_block` computes `n*S-sA*sB` and `n*q-s*s` using float32 raw moments. A separate on-device experiment verifies that every raw sum, square sum and matrix product is exact against int64 values for these four inputs. Float32 subtraction then produces covariance numerators 0/3072/0/4096 instead of -2/3070/-2/4094. Widening those exact moments to float64 before the products/subtraction recovers reference R within 1.12e-16 in these cases.

That experiment neither patches CuGen nor proves a general remedy. At larger sample counts, raw moment accumulation can itself lose precision; pairwise missingness, other execution branches, invalid/monomorphic pairs, ALT orientation, memory and timing need separate tests. Do not automatically choose recoding, CPU fallback, private-function monkeypatching, or a revised precision contract.
