## Body

## TL;DR

Move genomeOS's committed data out of git and into a public Google Cloud Storage data store. Git keeps a small manifest for each data release. Anyone can download and verify the files over plain HTTPS without credentials.

## Why

`data/` is 259 MB tracked on `main`. 254 MB of that is `data/store/artifacts/` (61 artifact directories, including superseded v1/v2 alongside v3). Every clone pays for it, and the `.git` pack is 477 MB.

The owner's decisions:

- "all data, including surfaces, belong on GCP."
- "the data (raw data, harmonized data, surfaces, trained models) should be available to everyone, that's the point of genomeOS Atlas."

The repository is public, so everything in `data/` is already public. Mirroring it to a public bucket exposes nothing new.

## Scope

- **Bucket.** A dedicated public bucket in the existing project, separate from the Atlas web-data bucket (#406). It uses uniform bucket-level access and `allUsers` read. Object paths are immutable and versioned by release. Uploads refuse to overwrite: `--if-generation-match=0` plus a sha256 identity check.
- **Manifest.** Each release has a committed manifest listing every object's path, bytes, sha256 and media type. It also carries source and terms references wherever the repository already records them, including the existing non-commercial markers.
- **Fetching.** `scripts/fetch_data.py` downloads over public HTTPS, verifies sha256 and fails loudly on a mismatch, and caches under the git-ignored `data/`. The scripts that read `data/store` resolve their inputs through it.
- **Uploading.** The maintainer's upload and provisioning tools run through `scripts/gcloud_repo.py`. No bucket name or project id is committed; the public base URL is `GENOMEOS_DATA_BASE_URL`.
- **Leaves git.** `data/store/artifacts/**` and `data/validation/**` are untracked (`git rm --cached` plus `.gitignore`). History is **not** rewritten: reclaiming the pack is a separate, deferred decision.
- **Stays in git.** The hand-curated inputs reviewed by diff (`data/registry`, `data/sources`, `data/raw/afnd_populations.tsv`, `data/store/catalog-metadata.json`, `data/store/INVENTORY.json`) stay in git and are also published.
- **Trained models.** Fits exist only as pickles, so they are not published: loading a pickle from the internet executes code. A follow-up issue covers exporting them to a safe format.
- **Docs.** AGENTS.md, README, CONTRIBUTING, `docs/data-store.md` and `docs/hf-dataset-card.md`, plus clone advice (`git clone --filter=blob:none`).

Design: `docs/superpowers/specs/2026-10-17-data-store-on-gcs-design.md`. Related: #33 (private staging and data-version pinning) and #406 (public web-data bucket).
