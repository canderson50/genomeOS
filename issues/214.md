## Body

## Scientific objective / invariant

B0H must sample its declared beta-binomial population-count model, including
near-zero rho proposals, without changing priors or accepting invalid arithmetic.
Finite positive log mass for observed count outcomes is impossible. This is a
numerical likelihood defect, not GPU capacity or evidence of empirical model skill.
Advances the owner-authorized #211/#189 program and Atlas design §§7–8,12.

## Reproduction and observed failure

Core source: `bc0fbe0154772877c8046b4084ed9f520b5618c3` (PR213).
Nonconjugate test matrix frozen before execution in plan commit
`9bf9e07ddeb44f41cf01c34cabb38f26b331e7a2` on
`feat/global-af-heterogeneity-oracles`:

```python
cases = {
    'mixed': ((0,2),(1,3),(4,5),(8,8),(2,6)),
    'rare': ((0,20),(0,12),(1,18),(0,5),(0,0)),
    'unequal_an': ((0,1),(1,2),(2,4),(3,9),(12,20),(0,0)),
}
# Each pair is (AC, AN); variants are independently parameterized in one batch.
# mean ~ Beta(1,1), rho ~ Beta(1,9)
# chains=4, draws=2000, tune=2000, target_accept=.9, seed=42
```

`fit_reference_population_heterogeneity` produced **276 divergences**, all in
chain0. One explicitly labeled instrumented reproduction retained exactly that
outcome. No relaxed gate, different seed or selected passing retry was used.
The public fitter correctly refused the result through HeterogeneityConvergenceError.
Worst R-hat1.53119, minimum bulk ESS7.14215, minimum tail ESS4.01606.

Chain0 froze at unequal_an mean `0.9120608465340185`, rho
`8.091265212637455e-18`, concentration `1.2359006579566026e17`.
Its adapted step size was `6.756087844473595e-14`; the other chains used
approximately0.324–0.450 and moved normally.

## Localized arithmetic cause

At that exact point, evaluate the unequal_an count likelihood with the JAXified
PyMC BetaBinomial graph, then compare with the separately anchored finite-product
identity. In logit(mean),logit(rho) coordinates:

| Calculation | Log likelihood | Gradient |
| --- | --- | --- |
| Current JAXified PyMC gamma differences | **+6160.0** | `[0.0,0.0]` |
| Independent finite-product reference | **-26.757334358778397** | `[-14.834190475224663,2.7841657124119296e-15]` |

PyMC6.3.1 implements this likelihood with `betaln`, whose local implementation
is a difference of `gammaln` terms. Cancellation at enormous concentration
creates a spurious high-density region that traps the adaptive sampler.
Other likelihood terms at the trapped chain's parameters agree closely with
the independent reference. A separate162point interior/near-boundary probe
found maximum gradient discrepancy below8e-11 when rho>=1e-4; ordinary-domain
agreement did not detect the extreme-proposal failure.

Runtime empirically verified with scripts/env_report.py: Python3.12.13,
PyMC6.3.1, PyTensor3.3.0, JAX/JAXlib0.11.1, NumPyro0.21.0, ArviZ1.3.0,
NumPy2.4.6, SciPy1.18.1. Actual fits returned float64; separate graph probes
explicitly enabled JAX float64. `nuts={'chain_method':'vectorized'}` reaches
the sampler with target_accept0.9 as intended.

## Required fix and acceptance evidence

- Numerically stable differentiable evaluation of the same beta-binomial law;
  no prior truncation, concentration clipping, Binomial substitution, changed
  data, relaxed convergence gates, or favorable seed selection.
- Preserve the production count-domain/output refusal rules. A proposal may
  explore outside the output scorer's supported concentration range, so an
  output-only validation check cannot repair the sampler's potential.
- Independent value AND logit-gradient regressions at the trapped point and
  a declared wider domain, including small/large counts and extreme priors.
- Keep memory/work bounded; do not allocate observation-by-full-AN support
  matrices or import private numerical helpers across module boundaries.
- Rerun the unchanged frozen actual-sampling comparisons after the localized
  fix; retain this first failure and all other prescribed outcomes.
- Focused regressions, smoke, full CI and independent review before readiness.

No real genomic data, fitted population surface or private artifact was involved.
PR213's previously green exact-case tests/CI are valid but insufficient evidence
for these broader cases; mark its readiness accordingly until this is resolved.
