## Body

## Problem

In the compact left options panel, the Statistical elevation label and numeric height value consume most of the row, leaving the height slider unnecessarily narrow. This makes precise adjustment harder even though horizontal space is available below the label.

## Expected

- the height slider uses substantially more of the control row width
- the label, information trigger, current multiplier, and slider remain legible without overlap
- the layout stays usable at the supported compact sidebar width
- keyboard and pointer behavior remain unchanged

## Contract

1. **Product claim:** users can adjust statistical elevation precisely from the compact Atlas sidebar.
2. **Acceptance evidence:** a browser layout assertion verifies the slider receives a practical minimum width at the compact viewport.
3. **Engineering interface:** the existing Inferred surface controls and Atlas stylesheet; no scene or scientific-state changes.
4. **Assumptions and consumers:** retain the current 0.25–5 range, URL state, label, and accessible input; only layout changes.
