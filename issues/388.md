## Problem

The registered #384 GPU probe exposed a false convergence failure in the ordinary comparison arm. That arm fixes `activity_probability` analytically to exactly 1, but `summarize_sampler_diagnostics` asks ArviZ for R-hat and ESS over every posterior variable. R-hat/ESS are undefined for a constant, so both the initial fit and its doubled-budget retry were recorded as invalid because `activity_probability` had non-finite diagnostics.

This is an implementation bug, not evidence that the ordinary model failed to converge. Left unchanged, it would falsely reject all 360 ordinary-arm tasks and make the paired campaign impossible to finalize.

## Scientific contract

1. **Objective:** assess sampler convergence over variables that are actually sampled while preserving every registered divergence, R-hat, and ESS gate.
2. **Acceptance evidence:** an ordinary-arm regression containing constant `activity_probability=1` succeeds when its sampled variables pass; the spatial-activity arm still diagnoses its sampled activity parameters; a bad sampled parameter or any divergence still refuses the fit.
3. **Interface:** keep the shared `SamplerDiagnostics` record and `fit_spatial_activity_graph` public behavior; make the activity fitter provide the correct diagnostic variable set for its model arm.
4. **Assumptions/refusals:** do not drop arbitrary constant or non-finite sampled variables, weaken thresholds, change sampler settings, reinterpret the failed probe as scientific evidence, or reuse artifacts generated from the buggy source revision.

The fix must regenerate the #384 campaign manifest because its source hash changes. The retrieved probe artifact and telemetry remain private debugging evidence.

Blocks #384.
