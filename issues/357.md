## Body

## TL;DR

The new first-party coverage check roughly doubles the CI test runtime when it uses coverage.py's default tracer. Python 3.12 provides a lower-overhead tracing engine that gives the same 90.19% result and passes the complete 5,797-test suite.

## Objective

Keep the repository-owned coverage badge trustworthy without making every CI run pay avoidable tracing overhead.

## Acceptance evidence

- Run the complete test suite with `COVERAGE_CORE=sysmon` on Python 3.12.
- Confirm all tests pass.
- Confirm the covered and total statement counts match the default tracer.
- Confirm the generated coverage SVG is unchanged.
- Confirm the GitHub Actions test job passes with the optimized engine.

## Engineering change

Set `COVERAGE_CORE=sysmon` only on the Python 3.12 CI test step. Do not make it a project-wide coverage setting because genomeOS still supports Python 3.11.

## Assumptions and consumers

The coverage contract measures statements only. It does not currently use branch coverage, dynamic contexts, or coverage plug-ins. Contributors and branch protection consume the CI result; the README consumes the generated SVG.
