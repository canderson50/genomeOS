## Body

## Product claim

The inferred-surface cell boundaries should be visible on initial Atlas load and described in plain language as **Cell outlines**, so users can immediately distinguish the discrete model cells behind a continuous-looking surface.

## Measurable output and acceptance evidence

- A URL with no `edges` parameter initializes the layer as enabled.
- The Layers control is labeled `Cell outlines` and its accessible info label uses the same term.
- Explicit shared URLs (`edges=false` and `edges=true`) continue to override the default deterministically.
- URL-state unit tests and browser tests cover the new default and label.

## Engineering interface

Update the Atlas URL-state default and the Layers UI label, retaining the existing `cellEdges` internal contract and `edges=` URL parameter for backward compatibility.

## Assumptions, refusal conditions, and consumers

This is a rendering default only; it does not alter inferred values, model geometry, observation data, or provenance. Existing shared links must retain their explicit setting. Consumers are Atlas users and browser automation.
